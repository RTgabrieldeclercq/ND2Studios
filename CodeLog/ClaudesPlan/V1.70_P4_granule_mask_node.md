# V1.70 · P4 — Volume Mask node (`special:granule_mask`)  [wishlist Node 3]

**Depends on:** P0 contracts. **Concurrent with:** P1–P3, P5. **Pure backend + one
page handler.** This is the **object-producing** node (feeds the scope lever /
DVC-on-object / Node-4 viewer).

## Goal

Voxelize each granule's tessellated boundary onto the confocal grid, apply the
user's **smoothing parameter** (SDF-Gaussian), and publish per-granule `(Z,H,W) bool`
masks + a combined `(Z,H,W) int32` label volume — stored to mirror `record._mask3d_by_m`
so the entire V1.65–V1.68 back half consumes it unchanged.

- Confocal grid: `Z,H,W = shape_zhw`; a voxel center at index `(z,y,x)` maps to world
  `(x*dx, y*dy, z*dz)` µm. **z-plane assignment uses `floor`** (P0 decision 8): a
  boundary point at world z maps to plane `floor((z_um - z0)/dz)`.
- **Inside-test** (per granule): use `GranuleBoundary.delaunay.find_simplex(voxel_centers_um) >= 0`
  (cheap, reuses P3's triangulation); Voronoi-mode granules without a `Delaunay` get a
  mesh point-in-polyhedron test (ray casting on `vertices_um/faces`) or a
  `Delaunay(vertices_um)` built here.
- **SDF-Gaussian smoothing** (reuse the `mask3d.py` idiom, `distance_transform_edt`
  `mask3d.py:97`): `sdf = edt(mask) - edt(~mask)`; `sdf = gaussian_filter(sdf, sigma=
  smooth_sigma, sampling honors (dz,dy,dx))`; `mask = sdf > 0`. Non-shrinking, smooth
  surface — matches "continuous smooth volume".
- Combined label: paint each granule id into a `(Z,H,W) int32` (0 = background); on
  overlap, higher-density (or lower-id) granule wins — document the tie-break.

**Params** (P6): `smooth_sigma` (float µm, the wishlist smoothing parameter; 0 = off),
`fill_holes` (bool, `binary_fill_holes`), `min_object_voxels` (int; drop specks),
`all_multipoints` (bool).

## Page handler — `_run_granule_mask(node)`

Model on `_run_mask3d_node`. Per `(m,t)`: read `record._granule_tess_by_m[m][t]`;
`shape_zhw` from `record._raw_volume` (n_zslices,H,W); spacing via
`prep.spacing_from_volume`. Call `build_granule_masks`; store per-granule bool dict →
`record._granule_masks_by_m[m][t]` and combined int32 under the `"_labels"` key
(P0 §2). `_run_finish_node`. **Register `special:granule_mask` in `op_produces_objects`**
(done in P6) so the Frame/Object lever appears on its outgoing edge.

## Reuse note (back half is free)

`record._granule_masks_by_m[m][t]` has the same `{id:(Z,H,W) bool}` value type as a
single `_mask3d_by_m` object, so: `object_scope.iter_objects` (per-bool path) →
`ObjectRegion`s; the V1.68 scope lever → per-object DVC; `viz3d.surface.build_object_surface`
→ Node-4 surface. **No changes to those modules** (the combined int32 is a convenience;
its first-class support is the P6 `iter_objects` extension, P0 §6).

## Verification

- Analytic sphere boundary → voxel count ≈ `4/3πr³ / (dz·dy·dx)` within a few %;
  inside/outside correct at voxel centers.
- Anisotropic `(dz,dy,dx)` → `floor` z-assignment lands boundary on the right planes;
  no squashing.
- `smooth_sigma>0` does **not** shrink volume beyond tolerance (SDF property); corners
  rounded, not eroded.
- Two touching granules → combined int32 has a clean label seam; per-granule bool
  volumes each pass `iter_objects` as one 3-D object.
