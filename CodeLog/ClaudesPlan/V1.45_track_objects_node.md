# V1.45 — "Track Objects" node (centroid linker with thresholds)

## Goal

Refine object tracking and turn it into a first-class, configurable node in the
Pipelines tab.

1. **Refine the centroid linker** so the per-track reference centroid updates
   frame-to-frame (a moving reference that follows each object) and so a track
   can survive short detection gaps (occlusion / missed segmentation).
2. **Rename the special node `Validate Tracked Objects` → `Track Objects`.** The
   node no longer pops up the accept/reject dialog — it *performs* the tracking
   with user-chosen thresholds. (Interactive accept/reject still lives in the
   separate **Review Object** node, which is unchanged.)
3. Expose **thresholds that decide when an object is no longer linked**: a
   distance threshold (pixels *or* µm), a size-difference threshold, a minimum
   track length, and a maximum frame gap.
4. Make the tracking **method a choice param** so future methods (overlap / IoU,
   Kalman, …) drop in as new options. For now there is one method, named for
   what it is: **"Centroid (nearest-neighbor)"**.

## Approach

### Backend — `backend/object_tracker.py`
- `link_objects(...)` gains `method`, `max_size_diff_frac`, `max_frame_gap`, and
  `pixel_size_um` parameters (keeping the existing `max_displacement_px`,
  `min_track_length`, `min_circularity`, `max_eccentricity`).
- `_link_group` now carries `active[tid] = (cy, cx, area, last_frame)`:
  - the matched centroid/area **updates every frame** (moving reference);
  - a frame's cost matrix is the Euclidean centroid distance, **gated** by
    `max_displacement_px` *and* the size-difference fraction
    `|Δarea| / max(area)`;
  - the old hard "bounding-boxes must overlap" gate is dropped — pure centroid
    linking is what the method advertises;
  - unmatched tracks are **carried forward** up to `max_frame_gap` frames so they
    can re-link after a gap, instead of being dropped immediately.
- New helper `link_objects_with_params(rows, params, pixel_size_um=None)` maps the
  node's param dict (`method`, `max_distance`, `distance_unit`, `max_size_diff`,
  `min_track_length`, `max_frame_gap`) onto `link_objects` args, converting µm →
  px with `pixel_size_um`. Keeps the param translation Qt-free and shared by the
  Run and Preview paths.

### Registry — `pipeline_graph/registry_adapter.py`
- Add `SPECIAL_TRACK_OP_KEY = "special:track_objects"`. Replace the
  `Validate Tracked Objects` entry in `_SPECIAL_OPS` with `Track Objects`
  (hexagon, `PortType.ANY`). `SPECIAL_VALIDATE_OP_KEY` stays defined for
  migration / back-compat dispatch but leaves the palette.
- `param_specs_for(SPECIAL_TRACK_OP_KEY)` returns: `method` (choice),
  `max_distance` (float), `distance_unit` (choice px/µm), `max_size_diff`
  (float 0–1), `min_track_length` (int), `max_frame_gap` (int).

### IO — `pipeline_graph/io.py`
- Bump `PIPELINE_VERSION = 3`; add `_migrate_v2_to_v3` that retargets any
  `special:validate_tracks` node to `special:track_objects`, retitles it
  `Track Objects`, and seeds the default track params. `load_pipeline` chains
  v1→v2→v3 by stored version.

### Page — `pages/pipelines_page.py`
- Run: `_run_execute_node` routes `SPECIAL_TRACK_OP_KEY → _run_track_objects`,
  which re-links the accumulated rows (`_ensure_run_rows`) with the node params
  (authoritative over the default per-M tracking) and repopulates the table.
- Preview: `_preview_execute_walk_node` re-links the screened rows for the node.
- Popup edit button now only for **Review Object** (Track Objects renders its
  flat params directly; no editor dialog).

### Self-test / docs
- `_pipeline_graph_selftest.py`: rename the `"Validate"` spec lookup to
  `"Track Objects"`, add a `link_objects` size/distance/gap check, and a
  v2→v3 migration round-trip.
- Update `CHANGELOG.md` and `ARCHITECTURE.md`.

## Key decisions
- **Track vs. Review split.** `Track Objects` computes links; `Review Object`
  keeps the accept/reject dialog. Two distinct, single-purpose nodes.
- **Default tracking preserved.** The implicit per-M `link_objects` after
  measurement still runs (so Review/if-else work without an explicit node); a
  `Track Objects` node simply re-links with the chosen thresholds.
- **Permissive defaults** (`max_size_diff=1.0`, `max_frame_gap=0`,
  `max_displacement_px=100`, `min_track_length=2`) reproduce today's behavior
  for pipelines that don't tighten them.
- **Schema bump + migration** (v3) so old graphs' `Validate Tracked Objects`
  nodes become `Track Objects` cleanly.
