# V1.45 — Digital Volume Correlation (ALDVC port)

**Status:** In progress (Phase 0)
**Author:** Claude (with A. McGhee)
**Related research:** [Research/aldvc_literature_review.md](../../Research/aldvc_literature_review.md)
**Reference:** FranckLab ALDVC (MATLAB) — https://github.com/FranckLab/ALDVC

## Goal

Add the ability to measure 3D deformation in ND2Studios by porting FranckLab's
**Augmented Lagrangian Digital Volume Correlation (ALDVC)** from MATLAB to a
clean-room Python implementation that:

1. Computes a dense displacement field `u(x)` + strain tensor field between a
   reference volume and a deformed volume.
2. Saturates all available cores/RAM using the existing
   `compute/parallel` (process pool + shared memory) and `compute/gpu` (CuPy)
   infrastructure — the same way ND2 loading does.
3. Bakes into the GUI as a first-class capability (sidebar page + worker +
   result viewer) without disturbing any existing feature.

## Scope (V1.45 — confirmed with user)

| Decision | Choice |
|----------|--------|
| V1 deliverable | **Single reference→deformed pair, end-to-end** (displacement + strain). Multi-frame tracking deferred. |
| Compute | **CPU first (numpy/scipy + process pool), with an optional CuPy GPU path** (try-import, CPU fallback) for the FFT seed + resampling. |
| Dimensionality | **3D DVC *and* 2D DIC** — same engine, dimension `d ∈ {2,3}`; 2D = quad mesh + 6-DOF warp. |
| Validation | **Synthetic known deformations + Python oracle** (SPAM/pyxel in a throwaway env). No MATLAB / bit-for-bit requirement. |
| Global step | **FD operator first** (FranckLab-recommended); FE (hex/quad) deferred. |
| Interpolation | scipy cubic B-spline (`map_coordinates order=3`) — small subvoxel diff vs MATLAB `ba_interp3` accepted. |
| Strain measures (V1) | infinitesimal + Green–Lagrange first; Eulerian-Almansi/Hencky easy follow-ons. |
| Persistence | Persist fields to `.nd2s` (NPZ companion) — nice-to-have, may land in a later phase. |

## Why a new registry (not EnhancementPlugin / AnalysisPipeline)

- `EnhancementPlugin.execute(volume, ...)` is `(T,H,W) → (T,H,W)`, Z-collapsed,
  chainable, in-place. DVC needs `(Z,H,W)` volumes and produces a vector field.
- `AnalysisPipeline.run(channels, ...)` takes **already Z-collapsed** `(T,H,W)`
  channels and returns `AnalysisResult` (label masks + per-object measurements)
  — cannot hold a dense displacement/strain field.
- → Introduce a **third registry `DVCMethod`** (in `core/dvc_registry.py`),
  modeled byte-for-byte on `AnalysisPipeline`'s register/get idiom, **reusing
  `ParamSpec`** from `plugin_registry`, with its own `DVCResult`/`DVCParams`.

## Data source (no loader changes needed)

The full 3D volume already survives into RAM:
`MaterializedDataset.channels[name]` is `(M,T,Z,H,W)`;
`channel_array(name, m)` returns the raw block; `channels[name][m,t]` is
`(Z,H,W)`. DVC reads `record._raw_volume` and pulls
`vol_ref = block[t_ref]`, `vol_def = block[t]`. **DVC must never route through
`to_lazy_channel` / the recipe / enhancement path** — those force the Z-collapse.
Physical units (`pixel_size_um`, `z_step_um`) come from the dataset/metadata.

*Optional ergonomic accessor (later):* `MaterializedDataset.volume_pair(c, m,
t_ref, t) -> (Z,H,W),(Z,H,W)` to centralize the lookup + voxel-size resolution.

## Parallelism plan (saturate cores + RAM)

- Qt boundary: one `DVCWorker(BaseWorker)` on its own QThread, iterating the
  (single, for V1) volume pair; it owns **no** parallelism itself.
- Inside the engine, the two hot stages fan out across all physical cores via
  `multiprocessing.shared_memory` (`shared_ndarray`/`attach_shared`) + a
  `ProcessPoolExecutor`, sized by `recommended_worker_count()` (`min(cores, 8)`):
  - **Stage 1 (FFT seed)** — subset-center blocks; ref + def volumes in shared
    memory once.
  - **Stages 3 & 5 (IC-GN sweep)** — element-index blocks; ref vol, prefiltered
    def vol, and ref gradients in shared memory; the per-subset kernel is a
    **module-level importable function** (closures can't pickle into children).
- **Note:** the existing `process_map_planes` dispatches `stack[idx]` (one
  plane per task) — it does *not* fit DVC, where each worker needs several
  whole shared arrays + a block of subset centers. We add a thin DVC dispatcher
  in `backend/dvc/parallel.py` built directly on `shared_ndarray`/`attach_shared`
  (faithful reuse of the low-level primitives, not the plane-oriented wrapper).
- **GPU (optional):** route Stage 1 FFTs + resampling through `compute/gpu`
  (`to_xp`/`to_numpy`, `should_dispatch_to_gpu`) when CuPy is present and the
  user opts in; numpy/scipy CPU fallback otherwise.
- Stage 4 global sparse solve is inherently sequential — mitigated by caching
  the factorization across the L-curve sweep and ADMM iterations.
- RAM: full `(M,T,Z,H,W)` already resident; DVC adds one shared copy of the
  current pair + result fields. Respect `EAGER_MAX_FRACTION` + MemoryMonitor
  bands; for V1's single pair this is comfortably bounded.

| Stage | ALDVC source | Python module | Parallel |
|-------|--------------|---------------|----------|
| 0 Volume prep + normalize | `ReadImageLarge3`, `funNormalizeImg3` | `dvc/__init__.py` (`run_aldvc`) | serial |
| 1 FFT integer seed + subvoxel + qfactor | `IntegerSearch3Multigrid`, `funIntegerSearch3` | `dvc/integer_search.py` | process pool / GPU |
| 2 Outlier clean + mesh + DOF init | `RemoveOutliers3`, `inpaint_nans3`, `MeshSetUp3`, `Init3` | `dvc/outliers.py`, `dvc/mesh.py` | serial/vectorized |
| 3 Local IC-GN (Subpb1, pass 1) | `LocalICGN3`, `funICGN3` | `dvc/icgn.py` | **process pool** |
| 4 Global compatibility (Subpb2) | `Subpb13`+`funDerivativeOp3` (FD) | `dvc/global_step.py` | sequential solve (cached factor) |
| 5 Modified local IC-GN (ADMM) | `Subpb13`, `funICGN_Subpb13` | `dvc/icgn.py` | **process pool** |
| 6 Dual update + ADMM loop | `main_ALDVC.m` ADMM block | `dvc/admm.py` | serial (cheap) |
| 7 Strain tensor + units | `ComputeStrain3`, `funCalculate*Eij` | `dvc/strain.py` | vectorized |
| — Parallel dispatch | (Parallel Computing Toolbox parfor) | `dvc/parallel.py` | — |
| — Result container | — | `dvc/result.py` (`DVCResult`, `DVCParams`) | — |

GUI/wiring: `core/dvc_registry.py` (`DVCMethod` base), `workers/dvc_worker.py`,

## Roadmap

- **Phase 0 — Docs + scaffolding (this commit).** Literature review + this plan;
  `backend/dvc/` package skeleton; `core/dvc_registry.py` (`DVCMethod` +
  `DVCResult`/`DVCParams`); a no-op `ALDVCMethod` that returns a dummy field;
  `DVCWorker`; `DVCPage`; force-import + `Settings.PAGES`/`PAGE_PREREQS` wiring.
  Goal: "DVC" appears in the sidebar and runs end-to-end with a dummy result;
  `grep` confirms **no PySide6 import under `backend/dvc/`**.
- **Phase 1 — Mesh + DOF + indexing foundation.** `mesh.py` (regular hex/quad
  mesh, DOF pack/unpack, all `order='F'`/0-based helpers centralized);
  `outliers.py`. Unit-tested in isolation (the single highest-risk boundary).
- **Phase 2 — FFT integer seed.** `integer_search.py` with process-pool fan-out
  + shared memory + optional GPU. Validate on synthetic translations.
- **Phase 3 — Local IC-GN = conventional DVC.** `icgn.py`: 12-/6-DOF IC-GN,
  cached reference Hessian, warp composition, prefilter+`map_coordinates`,
  per-subset NaN isolation, process-pool fan-out. Validate on synthetic affine.
- **Phase 4 — Global step + ADMM.** `global_step.py` (FD operator + cached
  factorization + guarded L-curve + Tikhonov), `admm.py`. Full single-pair
  ALDVC. Validate convergence + denoising; cross-check vs Python oracle.
- **Phase 5 — Strain + units + worker/page integration.** `strain.py` (measures,
  smoothing, anisotropic voxel scaling); `DVCWorker` + `DVCPage` + field viewer;
  GUI end-to-end on a real loaded ND2 with full Z; optional GPU path live.
- **Phase 6 — Optional/deferred.** FE global step; incremental + cumulative
  tracking; `.nd2s` persistence of fields; richer 2D-DIC UI.

## Risks (and mitigations)

1. **Indexing/ordering** (1-based, `order='F'`, ndgrid axis order, swapped
   `(v,u)`) — silently scrambles the field. → centralize in `mesh.py`,
   unit-test on small grids.
2. **Interpolation kernel mismatch** — accepted; validate against Python oracle
   not MATLAB. Prefilter the deformed volume exactly **once**.
3. **IC-GN details** — reference-only cached Hessian, warp composition (not
   additive), `ddof=1`. Validate on synthetic affine.
4. **Global-solve fragility** — add Tikhonov + guard the L-curve fit.
5. **Parallelism foot-guns** — module-level kernels (pickle), parent-only
   `unlink`, per-process volume attach. Wrong → deadlock/corruption.
6. **Per-subset isolation** — try/except → NaN-then-inpaint per bad subset.
7. **Upstream merge-conflict markers** in `main_ALDVC.m` — port from HEAD only.

## Validation strategy

Synthetic (rigid / affine / smooth analytic deformation of a speckle volume,
recovered to subvoxel accuracy per stage) + an out-of-band SPAM/pyxel oracle in
a throwaway env (never imported by ND2Studios). Mesh/DOF layout unit-tested
against hand-computed expectations.
