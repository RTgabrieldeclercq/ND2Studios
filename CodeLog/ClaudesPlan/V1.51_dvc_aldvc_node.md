# V1.51 — Digital Volume Correlation as an analysis node (ALDVC port)

**Status:** In progress
**Author:** Claude (with A. McGhee)
**Supersedes:** `CodeLog/ClaudesPlan/V1.45_DVC.md` (the `Add-DVC` branch Phase-0 plan)
**Research:** [Research/aldvc_literature_review.md](../../Research/aldvc_literature_review.md)
**Reference:** FranckLab ALDVC (MATLAB) — https://github.com/FranckLab/ALDVC
(Yang, Hazlett, Landauer, Franck 2020, *Exp. Mech.* 60, 1205–1223)

## Goal

Measure 3D deformation in ND2Studios: a dense displacement field `u(x)` + strain
tensor field between a **reference** volume and a **deformed** volume, computed by a
clean-room Python port of FranckLab's **Augmented Lagrangian DVC (ALDVC)**, exposed as a
**first-class pipeline-graph analysis node** (not a standalone page).

## Why this supersedes the `Add-DVC` branch plan

The `Add-DVC` branch (commit `67086cf`) was cut from `1c7b173`, *before* V1.45's node
system and the SerialTrack subpackage existed. It delivered a good literature review, a
clean Qt-free `DVCMethod`/`DVCResult` registry, and a package skeleton — but the engine is
only a **global-shift stub** (no integer search / IC-GN / ADMM / strain), and it was wired
as a **sidebar page**. This version:

1. **Actually ports the algorithm** (the four ALDVC pillars).
2. **Integrates as a node** — a "Special" node (the `Track Objects` pattern) + a viewer
   panel (the `SerialTrackPanel` pattern), because a dense vector/tensor field fits neither
   `AnalysisPipeline` (masks/rows) nor `EnhancementPlugin` (`(T,H,W)→(T,H,W)`).
3. **Reuses SerialTrack math.** SerialTrack (a sibling FranckLab tool) already ports the
   sparse FD gradient operator (`funDerivativeOp3`), L-curve regularization, and the
   strain/derived-field maths. The genuinely new, DVC-specific work is **image-based subset
   correlation** (FFT integer seed + IC-GN) — SerialTrack starts from particle centroids and
   never registers image subsets.

## Key decisions

- **Scope per run:** a **full-timelapse field series** — one field per frame — played
  through in the DVC tab (updated from the original single-pair scope). `tracking_mode`
  = **cumulative** (each frame vs the fixed reference) or **incremental** (each frame vs
  the previous), faithful to `main_ALDVC.m`'s `ImgSeqNum = 2..N` loop. `z_start`/`z_end`
  and `downsample` keep deep/large stacks tractable.
- **Dimensionality:** auto-detect — 3D volumetric DVC when `Z>1` (raw `(Z,H,W)`), 2D DIC
  fallback (`(H,W)`). Same dimension-agnostic engine (`d∈{2,3}`). Primary target = 3D
  confocal Z-stacks.
- **Global step:** finite-difference operator (FranckLab-recommended default); FE deferred.
- **Interpolation:** `scipy.ndimage.map_coordinates(order=3)` (prefiltered B-spline); small
  subvoxel diff vs MATLAB `ba_interp3` accepted (validate against synthetic, not MATLAB).
- **Compute:** CPU numpy/scipy first; optional process-pool fan-out over subsets; GPU later.
- **Data path:** the node reads the un-collapsed volume directly from the record via
  `record._raw_volume.get_frame(c, m, t, z_mode="none")` (the accessor used ~14× in
  `pipelines_page.py`), bypassing the Z-collapse — DVC never routes through the recipe path.

## Data source (no loader changes)

`MaterializedDataset.channels[name]` is `(M,T,Z,H,W)` and `get_frame(..., z_mode="none")`
returns `(Z,H,W)`; physical scale is `record.pixel_size_um` / `z_step_um` →
`voxel_size_um=(z,y,x)`. The dataset must be loaded with Z retained; if the active record is
Z-collapsed, the node degrades to 2D DIC and surfaces a status hint.

## Algorithm → module map (`nd2studios/backend/dvc/`, all Qt-free)

| Stage | Module | New / reuse |
|-------|--------|-------------|
| Subset grid + DOF pack/unpack (0-based, `order='F'`, axis order, Neumann/Dirichlet sets) | `mesh.py` | **New** — centralizes the top correctness risk |
| Per-subset FFT integer seed + subvoxel + q-factor | `integer_search.py` | **New** (`numpy.fft`) |
| Local IC-GN subset solve (6/12-DOF, cached ref Hessian, warp composition, ZNCC `ddof=1`) | `icgn.py` | **New — the core** (`ndimage.spline_filter` + `map_coordinates`) |
| cc-threshold + median test + NaN inpaint | `outliers.py` | **New** (`ndimage.median_filter`) |
| Global aug-Lagrangian solve `(β·DᵀD+μI)û = β·Dᵀ(F−udual)+μ(u−vdual)` | `global_step.py` | **Reuse** `serialtrack.regularization._build_gradient_operator`, L-curve, `spsolve`; **new** = F-coupling term + Tikhonov + guarded fit |
| ADMM outer loop (≤4) + dual updates + convergence | `admm.py` | **New, thin** |
| F → strain (infinitesimal / Green-Lagrange / Almansi / Hencky) + voxel scaling | `strain.py` | **Reuse-thin** (`serialtrack/fields.py`) |
| Orchestration `run_aldvc(ref, def, voxel, params, progress_cb, cancelled_cb) -> DVCResult` | `engine.py` | Replace stub with staged pipeline |
| Process-pool fan-out (optional) | `parallel.py` | Deferred |

Reused as-is: `serialtrack/regularization.py`, `serialtrack/fields.py`,
`backend/serialtrack_analysis.py` (derived scalar fields for the panel),
`core/dvc_registry.py` (`DVCResult`/`DVCParams`/`DVCMethod`).

## Phased build (each phase verifiable)

1. **Mesh + engine skeleton + node/panel wiring** — node runs end-to-end; panel shows the
   seed field. Confirms Path-B plumbing on real data before numerics.
2. **Integer search** — validate on synthetic pure translation.
3. **Local IC-GN** — conventional local DVC; validate on synthetic affine `F`.
4. **Global step + ADMM** — full ALDVC; validate convergence + denoising.
5. **Strain + units + panel polish** (Z-slice scrub, stress, colormaps).
6. **Delivered follow-ups** — process-pool fan-out (`parallel.py`, default multicore
   via `n_workers`), opt-in GPU integer-search seed (`_ncc_fft` on CuPy, guarded),
   all-multipoints sweep, and the DVC viewer's Cell-Tracker scale controls
   (Auto / Min-Max / Global Scale) + image-viewer zoom toolbar (Home/+/−/Pan/zoom%,
   scroll-zoom, drag-pan).
   **Still deferred** — FE global step, incremental tracking, GPU IC-GN (needs
   batched-subset kernels), `.nd2s` field persistence.

## Risks

Indexing/order (centralize in `mesh.py`, unit-test); F-coupled solve vs SerialTrack's u-only
ADMM (verify against MATLAB `Subpb2` FD block); interpolation-kernel diff (accepted);
per-subset failure isolation (NaN-then-inpaint); compute time (single-pair bounds it);
dataset Z-preservation (degrade to 2D); backend purity (grep-gated, no PySide6 under
`backend/dvc/`).

## Validation

Synthetic known-deformation oracle (rigid / affine / smooth analytic) recovered to subvoxel
accuracy per stage, standalone script; mesh/DOF unit tests on small grids; GUI end-to-end on
a real 3D ND2 (launch with **Python312**); `grep -r PySide6 nd2studios/backend/dvc/` empty.
