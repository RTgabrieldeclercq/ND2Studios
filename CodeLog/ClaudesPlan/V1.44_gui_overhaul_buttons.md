# V1.44 — GUI Overhaul + Modern Button/Icon Revamp

## Goal

Migrate the navigation from a left sidebar to a **top tab bar**, give the app
**modern, DPI-scaling icon buttons** (qtawesome vector icons, e.g. a real
play/pause control), and **pin file metadata at the bottom of the right LUT
panel** so it is always visible.

## Approach

### Icon + DPI system — `nd2studios/widgets/icon_button.py` (new)

- `ui_scale()` / `scaled(px)` — single DPI factor from the primary screen's
  logical DPI (1.0 at 96 DPI). All new button/icon/tile sizes derive from this
  so the UI tracks the monitor instead of hard-coded pixels.
- `make_icon(name, color, …)` — recolored `qtawesome` (Font-Awesome) `QIcon`s on
  the Dracula palette. Vector ⇒ crisp at any DPI.
- `icon_button(...)` / `tool_button(...)` — `QPushButton` / `QToolButton`
  factories (DPI-scaled icon size, optional fixed square size, object name for
  QSS). `bind_toggle_icon(btn, off, on)` swaps a checkable button's icon on
  toggle (play ⇄ pause).
- The qtawesome import is guarded: a missing install degrades to text buttons
  rather than crashing. Added to `requirements.txt`.

### Top tab bar — `nd2studios/core/main_window.py`

- `_build_top_tabs()` replaces `_build_sidebar()`. A horizontal `#topTabBar`
  docks under the title bar: page tabs (`#topTabBtn` `QToolButton`s, icon +
  text, exclusive `QButtonGroup`, accent underline when checked) on the left;
  session actions (Save / Load / Configure / Performance / Macro,
  `#sessionTabBtn`) on the right.
- `_build_ui` body is now just the content area (the left sidebar + horizontal
  splitter are gone). Page switching still flows through the unchanged
  `_navigate(key)` → `QStackedWidget`. The sidebar animation/toggle code and the
  `_sidebar*` attributes were removed.
- Title-bar Min/Max/Close now use `icon_button` (`fa5s.window-minimize` /
  `window-maximize` / `times`).
- Theme: new `#topTabBar`, `#topTabBtn`, `#sessionTabBtn` QSS in `core/theme.py`.

### Right panel metadata — `widgets/lut_sidebar.py` + `multi_axis_viewer.py`

- `LutSidebar.set_metadata_text(str)` adds a **pinned** `#metaBox` below the
  scroll area (always visible, hidden only when the panel is collapsed).
- `MultiAxisViewer._update_axis_labels` mirrors the current frame's per-axis
  metadata (T time/Δt/elapsed, M pixel-size/resolution/FOV, Z step/height) into
  that block on every coordinate change, reusing the V1.43 `_frame_meta_text`.

### Play buttons

- The per-axis play buttons in `MultiAxisViewer` are now `icon_button` +
  `bind_toggle_icon("fa5s.play", "fa5s.pause")` (green when playing).
  `_set_axis_playing` no longer swaps button text.

## Key Decisions / Scope

- **Top tabs over a `PageShell` rewrite.** The defining structural change the
  user asked for is "tabs at the top." The existing pages already implement the
  left-controls / center-viewer / right-LUT arrangement inside their own
  splitters (recipe, analysis) with the `LutSidebar` already living in the
  viewer's right column. Rather than wrap all six pages in a new shared
  `PageShell` (a high-risk blanket rewrite of working layouts), V1.44 delivers
  the top tab bar, the pinned right-panel metadata, and the icon/DPI button
  system, leaving each page's proven internal layout intact. A future pass can
  extract a `PageShell` for uniformity if desired.
- **Hidden-slider model + qtawesome guard** keep the change additive and crash-
  safe.

## Verification

- Headless: `MainWindow` builds with all six top tabs; `_navigate` switches
  pages; viewer metadata mirrors into `LutSidebar._meta_label`.
- `run.py` starts cleanly (no tracebacks) with the new chrome.
- `icon_button` / `make_icon` / `bind_toggle_icon` produce non-null icons and a
  working play⇄pause toggle.
- Manual (real display): tabs sit along the top with crisp icons; the metadata
  block stays pinned bottom-right and updates as you scrub; buttons stay sharp at
  100 % / 150 % / 200 % Windows display scaling (relaunch after changing scale).

## Out of Scope

- A shared `PageShell` wrapper / uniform per-page layout refactor.
- Re-skinning every ad-hoc `QPushButton` across all pages (high-traffic chrome —
  title bar, tabs, play controls — is done; page-body buttons keep the refreshed
  QSS look).
