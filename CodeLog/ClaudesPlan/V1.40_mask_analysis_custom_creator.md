# V1.40 — Mask Analysis: Custom Mask Creator + Rename

## Goal

1. Rename the "Manual Mask" analysis pipeline to **"Mask Analysis"** across the UI and backend.
2. Add a **Custom Mask Creator** panel to the Mask Analysis pipeline: the user defines a rectangle-strip shape and a tiling direction; the pipeline auto-generates evenly-spaced, non-overlapping strips across the image. Each strip is its own labeled object in the Results tab, with stable IDs across every timepoint. Incomplete strips at the image boundary are excluded.

## Approach

### Rename

- `ManualMaskPipeline.name = "Mask Analysis"` in `manual_mask.py`
- `MANUAL_MASK_PIPELINE_NAME = "Mask Analysis"` in `analysis_page.py`
- All runtime logic references the constant — no other hardcoded strings needed.

### Custom Mask Creator — backend (`manual_mask.py`)

New public helpers:
- `generate_tiled_label_boxes(tiled_masks, H, W)` — returns `(y0, y1, x0, x1)` for each complete strip; excludes partial ones at the boundary.
- `generate_tiled_mask(tiled_masks, H, W)` — returns `(H, W)` int32 array for live-overlay preview.
- `rasterize_shapes(…, label_offset=0)` — new kwarg so drawn shapes never collide with tiled-strip IDs.

New hidden pipeline parameter: `tiled_masks` (list of spec dicts).

Modified `run()`:
1. Generate tiled boxes → paint into every frame with label IDs 1..N (stable across time).
2. Drawn shapes get offset IDs N+1, N+2, … per frame (existing logic, shifted).
3. Summary counts both tiled + drawn objects.

### Custom Mask Creator — UI (`analysis_page.py`)

New state: `self._tiled_masks: List[Dict[str, Any]] = []`

New `_custom_mask_group` (QGroupBox, hidden/shown alongside `_draw_group`):
- Shape type: Rectangle Strip (QComboBox, extensible)
- Direction: Vertical / Horizontal (QRadioButton pair)
- Strip height (px): QSpinBox, default 4096
- Full image width: QCheckBox (default checked); unchecked reveals width + X offset spinboxes
- Start offset (px): QSpinBox, default 0
- Generate Masks button → `_on_generate_tiled_masks()`: builds spec, updates `_tiled_masks`, refreshes label count, invalidates raster cache, updates overlay
- Count label: "N strips per frame" (calls `generate_tiled_label_boxes` with current image H/W)
- Clear Tiled Masks button → `_on_clear_tiled_masks()`

`_composite_overlay()` extended: tiled strips painted first, then drawn shapes with label offset.

`_screen_current_frame()` and `_on_run_next_m()` both inject `tiled_masks` into params alongside `frame_shapes`.

### Persistence (`experiment_manager.py`)

New `ND2StudiosRecord.tiled_mask_specs: List[Dict[str, Any]]` field, serialized as `"tiled_mask_specs"` in the .nd2s manifest (plain JSON list, no migration needed).

## Key Decisions

- **Stable tiled IDs across time**: tiled strips painted in every frame with the same label IDs (1..N). This means per-frame ΔArea columns in the Results tab correctly track the same spatial region over time.
- **No overlap between tiled and drawn**: drawn shapes are offset above the tiled range. A frame with no tiled masks uses offset 0 (IDs start at 1), so existing sessions without tiled masks behave identically.
- **Partial strip exclusion**: the `while y + strip_h <= H` condition is strict — the strip is only included if the full height fits. This is the "excluding masks that cannot be full" behavior the user requested.
- **Single spec per generate**: clicking Generate Masks replaces `_tiled_masks` with exactly one spec dict. The user can mix tiled strips with hand-drawn shapes on top.
