# V1.68 — DVC surface deformation metrics (UV-wrap / MDM) — Phase 3 of DVC-on-object

## Context

User request: *"Investigate deeply the UV wrap method and [Stout et al. 2016] to
replace the current 3D Mask Drawing → DVC pipeline. The data are 3D granules that,
upon drawing boundaries on each Z plane, form a 3D object like the paper's figures;
display the DVC data onto its surface. The surrounding factors acting on the 3D
object come from a different channel and must be an overlay option in the 3D viewer
after DVC compiles. Make the implementation generic to any data. Do not change how
DVC computes/functions directly — only how it is adapted to a surface as in the
paper."*

**Reference paper.** Stout, Bar-Kochba, Estrada, Toyjanova, Kesari, Reichner &
Franck, *"Mean deformation metrics for quantifying 3D cell–matrix interactions
without requiring information about matrix material properties,"* PNAS 113(11):
2898–2903 (2016). See `Research/` for the literature-review companion. The paper's
**Mean Deformation Metrics (MDM)** approach is *purely kinematic*: it takes an
already-measured 3D displacement field (they use FIDVC — our ALDVC engine is the
same family) and, on a **closed surface ∂V wrapped around the object**, computes a
mean deformation gradient via a **surface integral of the displacements**. It never
needs the matrix constitutive law and never re-solves the correlation — exactly the
"adapt DVC onto a surface, don't touch DVC" split the user asks for.

**Prior phases of this feature.**
- **Phase 1 (V1.65)** — the **3D Mask Drawing node** (`special:mask3d`) that draws
  the object across Z and publishes `record._mask3d_by_m = {m:{t:(Z,H,W) bool}}`.
  See `V1.65_mask_drawing_node.md`.
- **Phase 2 (V1.67)** — `dvc_object_field()` → `MaskedField` interpolated the DVC
  scalar onto the mask **voxels** and colored the mask iso-contour. See
  `V1.67_dvc_on_object_render.md`.

**Phase 3 (this plan) replaces the V1.67 object render completely.** The voxel-first
`MaskedField` path is retired as the primary object view; the primary artifact
becomes a **smoothed closed surface mesh** carrying the DVC displacement, with the
paper's full MDM metric suite and a 2D cartographic "unwrap." The voxel
interpolation is retained only as an internal helper for the optional *interior*
display.

## The method (paper → app)

The paper describes the motion of the matrix in continuum-mechanics terms,
`x(X,t) = u(X,t) + X` (Eq. 1), with deformation gradient `F = ∇x` (Eq. 2). Instead
of a pointwise `F`, it defines a **mean** deformation gradient over the object
volume `V0` (Eq. 3) and — the key step — converts that volume integral into a
**surface integral over the object boundary ∂V0** via the divergence theorem:

```
⟨∇u⟩ = (1/vol(V0)) ∮_∂V0  u ⊗ n  dA           (Eq. 6)
⟨F⟩  = I + ⟨∇u⟩                                (Eq. 7)
```

where `n` is the outward unit surface normal, `dA` a surface element, and `⊗` the
dyadic product. From `⟨F⟩` the standard metrics follow:

```
⟨J⟩          = det⟨F⟩                          (mean volume-change ratio / compressibility)
⟨F⟩          = ⟨R⟩⟨U⟩                          (polar decomposition)
⟨λ_i⟩, ⟨N_i⟩ = eigenvalues/eigenvectors of ⟨U⟩ (contractility + principal directions)
cos⟨θ⟩       = (tr⟨R⟩ − 1)/2                    (mean rotation, Eq. 8)
⟨Θ⟩          = ∫₀ᵗ |⟨θ(τ)⟩| dτ                  (cumulative rotation, Eq. 9)
```

Surface construction (paper, *Materials and Methods → Calculating Discretized Cell
Surfaces*): binary mask of the object → **marching cubes** (Lorensen & Cline 1987,
ref 40) → **Taubin smoothing** (Taubin 1995, ref 41). Displacements are then
**interpolated onto the surface** (paper Fig 2C) and decoupled into a **normal
component `u⊥ = u·n`** and a **tangential component `u∥ = u − u⊥ n`** (Fig 4C/D).
For viewpoint-independent inspection the closed surface is **parameterized to a
sphere and unwrapped to 2D** via the **Mollweide** (equal-area) homolographic
projection (Fig 4E–G) — this spherical UV parameterization *is* the "UV wrap."

Mapping to ND2Studios: the Phase-1 drawn mask is the binary object; ALDVC's
`DVCResult.displacement_field` is the measured `u`; the PyVista viewer renders the
colored surface + surrounding-channel context; a matplotlib sub-view shows the 2D
unwrap. **Nothing in `backend/dvc/` is read-write — only `DVCResult` is consumed.**

## Goal

1. Build a **smoothed closed surface mesh ∂V** from the drawn `(Z,H,W)` mask
   (marching cubes + Taubin), in physical µm.
2. **Interpolate the DVC displacement vector** `u` onto the mesh vertices and
   decompose into `u⊥` and `u∥` (plus keep the existing DVC scalars sampled on the
   surface).
3. **Color the surface** by `|u|`, `u⊥` (divergent red=outward/blue=inward, per
   Fig 4C), `u∥` magnitude, or any DVC scalar; keep the four render modes for the
   optional interior.
4. Compute the **MDM suite** — `⟨∇u⟩`, `⟨F⟩`, `⟨J⟩`, `⟨λ_i⟩`+`⟨N_i⟩`, `⟨θ⟩`, and
   `⟨Θ⟩` accumulated over the frame series — and report it in the DVC panel.
5. Provide a **2D UV-unwrap map** (equirectangular + Mollweide) of the chosen
   surface scalar, with `u∥` streamlines (Fig 4F/G).
6. **Surrounding-channel context overlay** in the 3D viewer: a *different* channel
   rendered as a translucent **volume/MIP cloud AND/or an iso-surface shell**,
   user-selectable with an opacity control, shown around the object after DVC
   compiles.
7. **Generic to any data**: any object mask, any DVC channel, any context channel —
   validated on the paper's analytic cases, not neutrophil-specific.

## Approach (builds on existing infra; Qt-free maths in `backend/`)

### 1. Surface geometry + on-surface sampling — `backend/viz3d/surface.py` (new, pure numpy/scipy/skimage)

- `@dataclass ObjectSurface`: `vertices_um (Nv,3)` world `(x,y,z)`, `faces (Nf,3)`
  int, `vertex_normals (Nv,3)`, `face_normals (Nf,3)`, `face_areas (Nf,)`,
  `face_centroids_um (Nf,3)`, `enclosed_volume_um3: float`, `centroid_um (3,)`,
  `scalars: Dict[str,(Nv,)]`, `default_scalar: str`.
- `build_object_surface(mask (Z,H,W) bool, voxel_size_um (dz,dy,dx), *,
  smooth_iterations=10, taubin_lambda=0.5, taubin_mu=-0.53, step_size=1) ->
  ObjectSurface` — `skimage.measure.marching_cubes(mask, level=0.5,
  spacing=voxel_size_um)` (already a core dep) gives verts/faces/normals in µm;
  `_taubin_smooth()` applies the λ|μ pass over the vertex adjacency built from
  `faces` (pure-numpy, ~20 lines — keeps the module PyVista/VTK-free like
  `overlays.py`); normals/areas/centroids recomputed post-smoothing. Enclosed volume
  by the divergence theorem `V = (1/6) Σ_faces v0·(v1×v2)` (sign-consistent with
  Eq. 4), so `V` and the surface integral share one triangulation.
- `sample_displacement_on_surface(result, surface, *, z_offset_um=0.0) -> (Nv,3)` —
  reuses the **µm-aligned `RegularGridInterpolator`** scheme already proven in
  `dvc_object_field` (`grid_coords × voxel_size_um` ↔ world µm), but interpolates
  the **three displacement components** at the mesh vertices (world `(x,y,z)` →
  native `(z,y,x)` sampling), returning per-vertex `u` in µm. Extrapolates past the
  DVC grid inset; 2-D DIC broadcasts over Z (as today).
- `decompose_surface_displacement(u_vert (Nv,3), vertex_normals (Nv,3)) ->
  (u_perp (Nv,), u_par_vec (Nv,3), u_par_mag (Nv,))` — `u⊥ = u·n`,
  `u∥ = u − u⊥ n`.
- Populate `surface.scalars`: `disp_mag`, `u_perp`, `u_par`, and the existing DVC
  scalar names (`u_x/u_y/u_z`, strains, `qfactor`) sampled at vertices via the same
  interpolator so the surface color picker is a superset of Phase 2's.

### 2. Mean deformation metrics — `backend/viz3d/mdm.py` (new, pure numpy)

- `@dataclass MDMResult`: `grad_u (3,3)`, `F (3,3)`, `J: float`, `R (3,3)`,
  `U (3,3)`, `stretches (3,)` = `⟨λ_i⟩` (sorted), `principal_dirs (3,3)` = `⟨N_i⟩`
  (columns), `theta_deg: float`, `dim: int`, `notes: str`.
- `mean_displacement_gradient(surface, u_vert) -> (3,3)` — the discrete form of
  Eq. 6: `⟨∇u⟩ = (1/V) Σ_faces (ū_f ⊗ n_f) A_f`, with `ū_f` the mean of the face's
  three vertex displacements, `n_f` the outward unit face normal, `A_f` the face
  area, `V = surface.enclosed_volume_um3`.
- `deformation_metrics(grad_u) -> MDMResult` — `F = I + ⟨∇u⟩` (Eq. 7);
  `J = det(F)`; polar decomposition via SVD (`F = WΣVᵀ ⇒ R = WVᵀ`, `U = VΣVᵀ`);
  `stretches`/`principal_dirs` = eig of `U`; `cos θ = (tr R − 1)/2` (Eq. 8, clamped).
- `cumulative_rotation(thetas_deg, times_s) -> float` — trapezoidal `∫|θ|dτ`
  (Eq. 9) across the frame series → `⟨Θ⟩`.
- **Isolation note:** consumes only an `ObjectSurface` + a per-vertex `u`. Imports
  nothing from `backend/dvc/`. Validated against the paper's four canonical cases.

### 3. Overlay adapters + UV-unwrap — `backend/viz3d/overlays.py` (modify; `__init__.py` exports)

- Add `@dataclass SurfaceField`: `vertices_um`, `faces`, per-vertex `scalars`,
  `default_scalar`, `mdm: Optional[MDMResult]`, plus an optional `interior:
  Optional[MaskedField]` (for the interior display, built by the retained
  `dvc_object_field` helper).
- `dvc_object_surface(result, mask, mask_voxel_size_um, *, z_offset_um=0.0,
  scalar_keys=None, smooth_iterations=10, with_interior=False,
  with_metrics=True) -> SurfaceField` — orchestrates §1+§2: build surface, sample
  `u`, decompose, compute `MDMResult`, optionally attach an interior `MaskedField`.
  **This is the new primary object adapter; it supersedes the direct use of
  `dvc_object_field` for the object view.**
- `unwrap_surface(surface, scalar, *, projection="mollweide"|"equirectangular",
  width=512, height=256) -> UnwrapMap` — genus-0 spherical parameterization: each
  vertex direction from `centroid_um` → `(lon = atan2(y,x), lat = asin(z/r))`, then
  to 2D (equirectangular `(lon,lat)`, or Mollweide's equal-area auxiliary-angle
  solve). Rasterize the triangulated scalar into the 2D grid (barycentric fill),
  returning `(H,W)` value map + coverage mask + a tangential `(u∥)` vector field for
  streamlines. Pure numpy.
- **Retire** `MaskedField` as the *primary* object render; keep the class +
  `dvc_object_field` only as the `with_interior` helper.

### 4. Viewer render — `widgets/viewer3d/pyvista_viewer.py` (modify)

- `_add_surface_field_overlay(sf)` (replaces `_add_masked_field_overlay` in the
  overlay dispatch `_add_overlay_actor`): build `pv.PolyData(sf.vertices_um,
  faces)` **directly** (the mesh already comes smoothed from the backend — no VTK
  marching-cubes here), color by the selected per-vertex scalar (`u_perp` →
  divergent `coolwarm` centred at 0, per Fig 4C; `disp_mag`/`u_par` → sequential),
  `smooth_shading=True`. Optional `u∥` streamlines/glyphs from the tangential
  vectors (Fig 4D). Keep Iso/Slices/Volume-MIP for the optional `sf.interior`.
- **Context channel overlay** (surrounding factors): `set_context_channel(volume
  (Z,H,W), *, mode="volume"|"mip"|"iso"|"none", color, opacity, iso_percentile)` —
  render a *different* channel as a translucent cloud (reuses the existing
  `_add_channel_actor` additive/maximum path) and/or an iso-surface shell
  (`grid.contour([level])`), both toggle + opacity controlled. Composited with the
  colored object surface in one scene.

### 5. DVC panel — `widgets/dvc_panel.py` (modify)

- Extend the `"3D Object"` view (`_VIEWS`): `Colour:` selector (`cmb_obj`,
  `_OBJECT_SCALARS`) gains `u_perp`, `u_par`. Add:
  - a **"Surface metrics"** readout (compact grid) showing `⟨F⟩`, `⟨J⟩`,
    `⟨λ₁,λ₂,λ₃⟩`, `⟨θ⟩`, and the running `⟨Θ⟩` for the current frame/series;
  - a **context-channel** picker + `volume/MIP/iso/off` mode + opacity slider;
  - a **"2D Unwrap"** sub-view on the matplotlib canvas (equirectangular/Mollweide
    contour of `u⊥` + `u∥` streamlines).
- Rename `_ObjectFieldWorker` → `_SurfaceFieldWorker`: builds the `SurfaceField`
  (+`MDMResult`) off-thread with the **same generation-guard + coalescing** pattern
  (view-switch / scalar / scrub never freeze). Cache by `(incr, t, scalar,
  smooth_iterations)`.
- `set_data(..., masks, mask_voxel_size, context_provider=None)` — `context_provider`
  is a callable `(m,t,channel)->(Z,H,W)` for the surrounding channel.

### 6. Page wiring — `pages/pipelines_page.py` (modify)

- `_populate_dvc_panel` passes the mask series + raw voxel size (as V1.67) **plus** a
  `context_provider` closure over `record._raw_volume.get_volume(other_c_idx, m, t)`
  so the panel lazily fetches the surrounding channel for the overlay.
- The MDM `⟨θ⟩` per frame drives `⟨Θ⟩` across the series (frame timestamps from
  `record._frame_timestamps` / extended-metadata `frame_timestamps_s`, falling back
  to frame index).

- On `SPECIAL_MASK3D_OP_KEY` add `surface_smooth_iterations` (int, default 10) — the
  only *compute-affecting* surface knob. All display choices (color scalar, context
  channel, projection) live in the DVC panel, not node params (they need no re-Run).

## Data flow

```
wired channel ──IMAGE──▶ [3D Mask Drawing] ──BINARY──▶ [DVC (ALDVC)]     (DVC engine unchanged)
                              │ record._mask3d_by_m {m:{t:(Z,H,W) bool}}          │
                              │                                DVCResult.displacement_field (voxels)
                              └───────────────┬──────────────────────────────────┘
                                              ▼
        backend/viz3d/surface.build_object_surface   (skimage marching_cubes + Taubin) → ∂V mesh (µm)
        backend/viz3d/surface.sample_displacement_on_surface   (µm-aligned RGI) → u at vertices
                                              ▼
             decompose → u⊥, u∥                 mdm.mean_displacement_gradient → ⟨∇u⟩
                                              ▼                               ▼
        SurfaceField (mesh + per-vertex scalars)     mdm.deformation_metrics → ⟨F⟩,⟨J⟩,⟨λi⟩,⟨Ni⟩,⟨θ⟩
                                              ▼                               ▼ (over series) ⟨Θ⟩
   PyVista3DViewer._add_surface_field_overlay  +  set_context_channel(other channel: vol/MIP/iso)
   DVCPanel · "3D Object": colored surface  +  MDM readout  +  "2D Unwrap" (Mollweide/equirect.)
```

## Key decisions / caveats

- **DVC computation is untouched** (the user's caution). `backend/dvc/` is neither
  imported nor modified; the pipeline consumes `DVCResult` read-only. Everything
  here is *adaptation onto a surface*, exactly the paper's kinematic post-processing.
- **Surface-first replaces the V1.67 voxel object render.** The `MaskedField` voxel
  path survives only as the optional interior helper (`with_interior=True`).
- **Displacements live in the matrix around ∂V, not inside the object.** The surface
  integral samples `u` *on* the boundary (interpolated from the surrounding field) —
  so the object interior need not carry a field, matching the paper and the DVC-on-
  matrix reality. (This also informs Doc 2's per-object crop: keep surrounding
  context, don't mask it out.)
- **Meshing choices mirror the paper**: marching cubes (ref 40) + Taubin (ref 41);
  enclosed volume via the divergence theorem so `V` is consistent with Eq. 4.
- **Taubin in pure numpy** keeps `backend/viz3d` PyVista/VTK-free and headless-
  testable (as `overlays.py` already is).
- **UV unwrap distortion**: equirectangular pinches at the poles; Mollweide is
  equal-area (the paper's choice). Both offered; this is a *display* artifact only —
  the 3D surface and MDM scalars are unaffected.
- **Physical-µm alignment** (from V1.67) makes DVC↔surface robust to XY downsample
  and anisotropic Z; a rare DVC `z_start` crop still uses `z_offset_um` (default 0).
- **Generic**: no neutrophil/collagen assumptions — mask from any source, DVC on any
  channel, context on any other channel.
- Optional-dependency posture unchanged: PyVista/VTK gated exactly as the rest of the
  3-D subsystem (placeholder when absent); `skimage`/`scipy` are core deps.

## Verification

- **MDM validated on the paper's four canonical cases** (Fig 1): simple stretch
  `λ=[1, 1/1.5, 1.5]`, axial rotation `θ=45°`, simple shear `k`, and the Eshelby
  inclusion — recovered `⟨F⟩` matches the analytic form to the paper's tolerances
  (≈1e-12 for A–C, ≈1e-3–1e-5 for Eshelby). Unit tests in `tests/`.
- **Surface**: marching-cubes + Taubin on a synthetic sphere → `enclosed_volume_um3
  ≈ (4/3)πr³`; area-weighted vertex normals unit-length; on-surface interpolation of
  a synthetic **linear** displacement field is exact (so `⟨F⟩` is recovered exactly).
- **Unwrap**: a known lat/lon test pattern round-trips; Mollweide area-preservation
  check vs. equirectangular pole distortion.
- **Viewer** (off-screen VTK): colored surface + context overlay renders non-uniform
  in all modes; empty-mask path is graceful; context toggle/opacity behave.
- **Panel**: "3D Object" → surface build + render; scalar switch (`u⊥`/`u∥`/…)
  rebuilds; MDM readout updates per frame and `⟨Θ⟩` accumulates across the series;
  "2D Unwrap" renders; context-channel picker composites the other channel; switch
  back restores the 2-D canvas; `_SurfaceFieldWorker` coalescing + generation guard
  drop superseded builds.
- **Regression**: confirm `backend/dvc/` is byte-for-byte unchanged (git diff empty
  under `backend/dvc/`).

## Deferred / follow-on (not in this plan)

- Per-face (rather than per-vertex) scalar option; adaptive remeshing for very large
  meshes.
- `u∥` streamline seeding density controls on the 3D surface (2D unwrap streamlines
  are in-scope).
- Conformal (angle-preserving) parameterization as an alternative to the equal-area
  Mollweide.
