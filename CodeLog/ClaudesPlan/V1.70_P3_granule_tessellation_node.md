# V1.70 · P3 — Tessellation + density-merge node (`special:granule_tessellate`)

**Depends on:** P0 contracts. **Concurrent with:** P1, P2, P4, P5. **Pure backend +
one page handler.** This node also owns the **RAG density-merge** (it needs the
per-granule densities that only tessellation produces), so its output labels are the
**final** granule assignment P4 masks.

## Goal

Turn each granule's assigned points into a boundary, in **two selectable modes**
(both built — P0 decision 6), then **merge adjacent granules of similar density**
(iterative RAG — decision 7). Emit a `GranuleTessellation` (P0 §4).

## Backend — `nd2studios/backend/analysis/granule_tessellate.py` (Qt-free, `scipy.spatial`)

```python
def tessellate_granules(points_zyx, labels, voxel_size_um, params) -> GranuleTessellation
```

### Mode A — per-granule alpha-shape (concave hull)
- For each granule's points (in µm): `scipy.spatial.Delaunay(pts)`; drop tetrahedra
  whose circumradius > `alpha`; boundary = faces belonging to exactly one surviving
  tetra → watertight-ish concave hull (captures roughness/elongation/concavity).
  `alpha→∞` ⇒ convex hull (`ConvexHull` fallback). `enclosed_volume_um3` = Σ surviving
  tetra volumes. `density = n_points / enclosed_volume_um3`.
- Keep the `Delaunay` object on `GranuleBoundary.delaunay` so P4's inside-test is a
  cheap `find_simplex` (no re-triangulation).

### Mode B — global Voronoi
- `scipy.spatial.Voronoi(all_pts_um)`; per-point cell volume via `ConvexHull` of the
  cell's finite vertices; **clip unbounded outer cells** to the data bbox (drop
  infinite regions from the volume estimate). `density_i = 1/cell_volume_i`. A
  granule's region = union of its members' cells; boundary faces = cell faces on the
  outer hull of the union.

### RAG density-merge (both modes)
- Build a region-adjacency graph: Mode B ⇒ shared Voronoi ridge between cells of
  different granules; Mode A ⇒ hulls intersect OR centroid distance < `adj_dist`
  (use `cKDTree`, the app's ubiquitous idiom).
- Iterate: find the adjacent pair with `|ρi−ρj|/max(ρi,ρj) ≤ merge_tol`, merge
  (union-find + relabel), recompute the merged region's density/boundary; repeat
  until no pair qualifies. Record `merged_from`.
- Result: `point_labels` (final), `boundaries` (final per-granule), `mode`.

**Params** (P6): `tess_mode` (choice `alpha_shape|voronoi`), `alpha` (float; `visible_when
tess_mode==alpha_shape`), `merge_tol` (float 0–1, density-ratio tolerance),
`adj_dist_um` (float; alpha-shape adjacency), `min_granule_points` (int; drop/merge
tiny granules).

## Page handler — `_run_granule_tessellate(node)`

Per `(m,t)`: read points + labels; guard missing upstream; call `tessellate_granules`;
store `record._granule_tess_by_m[m][t]`; **write final `granule_id` back into rows**
so the Results tab reflects the merge; `_run_finish_node`.

## Verification

- Convex blob: alpha-shape (large α) volume ≈ `ConvexHull` volume; both watertight.
- Concave "banana" cloud: small α follows the concavity (hull would bridge it) —
  asserted by a point known outside the concave region being outside the alpha-shape.
- Two equal-density adjacent blobs deliberately over-split into 4 → RAG merge
  collapses to 2; two very different densities stay separate.
- Voronoi mode: Σ clipped cell volumes ≈ data-bbox volume; per-point density sane.
- `QhullError` on degenerate/coplanar input handled (fallback to convex hull / skip).
