# Plan: Multi-File Side-by-Side Import View

## Goal
Allow users to load multiple ND2/TIFF files simultaneously and view them
side-by-side on the Import page. Each file gets its own set of controls
(Browse, Z-mode, metadata table, channel info, Confirm, Stitch). Control
sidebars are individually collapsible and images auto-fit whenever a sidebar
is toggled or any splitter divider is dragged.

## Approach

### New widget: `FilePanel` (`nd2studios/widgets/file_panel.py`)
A self-contained widget bundling:
- **Header bar** (30 px): collapse toggle `◀ / ▶` | filename label | ✕ close button
- **Inner QSplitter** (horizontal): controls sidebar (220 px, collapsible) | MultiAxisViewer
- **Controls sidebar**: Browse, Reconstruct, Z-mode combo, frame-stride spinbox,
  metadata table, channel info scroll area, Confirm Import, Stitch M… buttons
- **`record: ND2StudiosRecord`** — can be set to an external record so writes
  go directly into the caller's experiment state (used by primary panel)
- **Signals**: `panel_close_requested(self)`, `loaded(metadata_dict)`
- **`fit_viewer()`** — calls `canvas.reset_zoom()` on the viewer, connected to:
  - The inner splitter's `splitterMoved` signal
  - The sidebar animation's `finished` signal

### Refactored: `ImportPage` (`nd2studios/pages/import_page.py`)
- Thin container: toolbar ("+ Add File" button) + horizontal outer QSplitter
- Manages list of `FilePanel` instances (`self._panels`)
- First panel is **primary**: its `record` is set to `exp_manager.active`;
  progress/status callbacks feed the main window status bar; Confirm updates
  the experiment status and triggers workspace/pyramid
- Additional panels are **secondary**: own standalone records; Confirm marks
  their local record as imported
- `load_from_experiment(exp)` / `save_to_experiment(exp)` delegate to
  `self._panels[0]` — backward compatible with all other pages
- `reset_all_viewers()` — called by `MainWindow._reset_active_viewer_zoom`
  to fit every panel when the left nav sidebar collapses/expands
- `viewer` property returns primary panel's viewer (backward compat for
  pages that do `page.viewer`)
- Primary panel cannot be removed (guard: `len(self._panels) <= 1 → return`)
- Outer splitter `splitterMoved` triggers `fit_viewer()` on all panels

### Minor update: `MainWindow._reset_active_viewer_zoom`
Checks for `reset_all_viewers()` method first (ImportPage); falls back to
single `viewer.canvas.reset_zoom()` for other pages.

### Theme: `nd2studios/core/theme.py`
Added QSS rules for `#filePanelHeader`, `QLabel#filePanelTitle`,
`QPushButton#filePanelCollapseBtn`, `QPushButton#filePanelCloseBtn`,
`#filePanelControls`.

## Files Modified
- `nd2studios/widgets/file_panel.py` — **new**
- `nd2studios/pages/import_page.py` — **rewritten** (functionality preserved)
- `nd2studios/core/main_window.py` — `_reset_active_viewer_zoom` updated
- `nd2studios/core/theme.py` — QSS styles added

## Key Decisions
1. **Primary panel record = exp_manager.active** — zero-copy sync; no secondary
   callback needed to keep the experiment record up to date.
2. **Minimum 1 panel** — close is a no-op when only one panel remains,
   preserving the current single-file behaviour as a degenerate case.
3. **Autofit on splitter drag and sidebar toggle** — connected at the
   `splitterMoved` / animation `finished` signals, not on a timer, so there
   is no perceptible lag.
4. **Secondary panels are view-only** — no recipe/export/workspace integration
   in V1.0; they are independent explorers.
5. **`_tile_source_summary` retained** — the detail row is removed from the
   FilePanel's simplified metadata table but the method is preserved in the
   old codebase for reference; it can be wired back via a callback later.
