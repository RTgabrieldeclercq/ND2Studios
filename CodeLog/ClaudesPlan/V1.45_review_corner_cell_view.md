# V1.45 — Whole-frame review: corner "cell-over-time" inset

## Goal

During **whole-frame object review** (Pipelines → *Review Objects* node,
`mode = "Whole frame"`), let the user **click a cell** to open a zoomed inset in
the top-right corner of the *same* viewer that shows that cell crop, **always
centred and outlined**, following the same **T** slider / playback so they can
watch the cell evolve over time. This replaces the original CellTracker "spatial
maps" view (which was never ported and is not functioning). Works for tracked
cells (animate across all their frames) and untracked single objects (one frame).
The inset also exposes **Accept Track / Reject Track**.

## Approach (all in `nd2studios/widgets/whole_frame_review_dialog.py`)

### Selection state + indexes
- `_track_index[m][track_id] = {t: row}` built in `__init__` alongside `_rows_at`.
- `_sel_track_id` / `_sel_row_id` (untracked, by `id(row)`); both `None` hides the
  inset. `_last_rgb` caches the full composite from `_render` so the inset crops
  from exactly what's displayed.

### Click reconciliation (`_on_canvas_clicked`)
- `QGuiApplication.keyboardModifiers()` (no signal change): **Alt/Ctrl-click** →
  existing toggle-reject; **plain click on a cell** → select (track id, else row
  id); **plain click on empty space** → clear selection.

### Corner inset (`_paint_overlay` → `_paint_corner_inset` / `_crop_for_row`)
- Constant square crop size from the selection's max bbox span × `_INSET_PAD`
  (`_crop_px_for_selection`) so scale is fixed; recentred on the current row's
  centroid each frame, clamped/padded to a fixed canvas so the cell stays centred
  at image edges. Label outlined via `analysis_page._overlay_labels`
  (`outline=True`, cyan). Drawn as a `QImage` into a top-right `QRect`
  (`_INSET_FRAC` of the smaller canvas dim) with a title strip
  (`Track N • T • area`). Gap frames show `no object at T`.
- The selected cell is ringed on the main frame in the centroid loop.

### Track actions (`_decide_track`)
- `Accept Track` / `Reject Track` buttons (shown only while selected) set
  `_decision[id(r)]` for every row of `_selected_rows()` — reuses the existing
  row-reference decision model, so `rejected_rows` / `accepted_rows` and the
  Run/preview apply paths are unchanged.

### Polish
- Selection cleared on `M` change, kept across `T` changes.

## Key decisions
- **Plain click selects, Alt/Ctrl-click rejects** (user-confirmed): the new
  inspect gesture is the primary one; reject moves to a modifier + the per-frame
  buttons + Reject Track.
- **Tracked + untracked** both supported (user-confirmed).
- **Reuse `_overlay_labels`** for the outline (same engine as the segmentation
  overlay and `TrackValidationDialog`) rather than a new contour path.
- No data-model or schema changes; everything is presentation on existing rows
  and masks already passed to the dialog.

## Verification
1. `python run.py` → pipeline Segmentation → Track Objects → Review Objects
   (`mode = Whole frame`); Run (or node *Edit…* preview).
2. Click a tracked cell → corner inset (centred crop + cyan outline + title).
3. Scrub T / Play → inset follows the track, recentres, constant scale; gap frame
   shows `no object at T`.
4. Click an untracked object (no Track Objects upstream) → single-frame inset.
5. Alt-click → toggles red reject (plain click still selects).
6. Reject Track → all frames of the track go red; `Done` → `rejected_rows`
   includes every row of the track.
7. Click empty space → inset closes.
