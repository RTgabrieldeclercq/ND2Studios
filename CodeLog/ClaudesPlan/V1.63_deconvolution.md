## 1. Goal

Add **deconvolution** to ND2Studios: given a fluorescence acquisition and a point
spread function (PSF), recover an estimate of the true fluorophore distribution by
inverting the microscope's optical blur. The design is **3D-first** — true volumetric
`(Z,H,W)` deconvolution with a 3D PSF is the primary target, and 2D single-plane
deconvolution **falls out as the degenerate case** (`Z==1`, a 2D PSF) handled by the
*same* dimension-agnostic engine (`d ∈ {2,3}`), exactly as the DVC node auto-selects
2D DIC vs 3D DVC.

Deconvolution must:

1. Consume the **raw, un-collapsed** `(Z,H,W)` volume — ND2Studios collapses Z at load
   for the recipe/export path, so deconvolution cannot be a normal `EnhancementPlugin`.
2. Support both a **theoretically computed PSF** (from optical metadata already in the
   ND2 file) and an **imported measured PSF** (bead image), following Nikon.
3. Expose a **rich, Nikon-faithful parameter set** (§5) so the McGhee Lab can fine-tune.
4. Produce a **restored image volume** that either (a) is Z-projected back into the
   normal `(T,H,W)` recipe/export stream ("restore-then-project"), or (b) is persisted
   / exported as a full restored `(T,Z,H,W)` stack.

Non-goals for V1.63: a learned/AI denoiser (Nikon's *Denoise.ai / Clarify.ai*),
GPU-only kernels as a hard dependency, and blind PSF estimation as the *default*
(blind is scaffolded but off by default; RL with a known PSF is the default).

## 2. Background & research summary

### 2.1 Image-formation model

A fluorescence microscope is, to good approximation, a linear shift-invariant system
corrupted by signal-dependent (Poisson / shot) noise. The recorded image `d` relates to
the true object `x` and the PSF `h` by

```
d = Poisson( h ⊛ x ) + read_noise
```

where `⊛` is convolution (2D or 3D). In the Fourier domain the PSF becomes the
**optical transfer function** `H = F{h}`; the microscope multiplies the object's spectrum
by `H`, which is band-limited (zero beyond the cutoff `2·NA/λ` laterally) — information
past the cutoff is lost, and near the cutoff it is attenuated and noise-dominated. This is
why naive inverse filtering (`X̂ = D / H`) explodes: it divides noise by ~0. Deconvolution
is therefore an **ill-posed inverse problem** that must be *regularized* — either
explicitly (a penalty term) or implicitly (stopping an iterative solver early).

### 2.2 Richardson–Lucy (the workhorse)

Richardson–Lucy (RL) is the maximum-likelihood estimator for **Poisson** noise, derived
independently by Richardson (1972) and Lucy (1974). It is iterative, multiplicative, and
**conserves total intensity** while keeping the estimate **non-negative** — both physically
correct for photon-counting fluorescence. The multiplicative update (element-wise `·` and
`/`, `⊛` convolution, `ĥ` the point-mirrored PSF) is:

```
              ⎛        d          ⎞
x_{k+1} = x_k · ⎜ ĥ ⊛ ─────────── ⎟          ĥ(m) = h(−m)
              ⎝     h ⊛ x_k       ⎠
```

Read it as: blur the current estimate (`h ⊛ x_k`), compare to the measurement by ratio
(`d / (h ⊛ x_k)` — 1.0 everywhere means "perfect"), back-project the correction through
the mirrored PSF, and rescale the estimate. If the PSF is not normalized to unit sum, the
update is divided by the back-projected unit image `ĥ ⊛ 1` for correctness. It provably
ascends the Poisson log-likelihood and, if it converges, reaches the ML solution
(Shepp & Vardi 1982).

**Iteration count is the primary knob.** RL has no natural stopping point: too few
iterations under-sharpens; too many amplify noise and produce "speckle"/ringing because RL
prefers sparse, over-fit solutions. Nikon's guidance (which we adopt as defaults): at
least 10 iterations, **optimally 30–60**, and **>60 rarely helps**. Nikon's *Automatic*
mode picks a modality-dependent cap (§2.5, Table A).

**Acceleration.** Plain RL is slow. Biggs & Andrews (1997) "vector acceleration" adds a
momentum/prediction step (extrapolate `x_k` along `x_k − x_{k−1}` before the multiplicative
update), giving ~2–3× fewer iterations for the same result at negligible cost. Nikon
explicitly ships the "**Accelerated** Lucy-Richardson algorithm with noise regularization,"
so acceleration + a noise term are part of matching their behavior.

**Regularization.** Two complementary controls:
- **Total-Variation RL (RL-TV)** — Dey et al. (2006) multiply the update by a TV factor
  `1 / (1 − λ_TV · div(∇x_k / |∇x_k|))`. TV suppresses noise amplification while preserving
  edges; `λ_TV` (≈ 0.001–0.01) is the strength. This is our explicit noise-regularization
  term (maps to Nikon's "noise regularization" / SNR knob).
- **Early stopping / damping** — a "noise level" (SNR) parameter that damps the correction
  ratio in low-signal regions, plus optional auto-stopping when the estimate stabilizes.

### 2.3 The other methods (mapped to Nikon, scaffolded not deeply built)

| Nikon method | Algorithm | One-line role |
|---|---|---|
| **Richardson-Lucy** | Accelerated RL + noise reg. (Poisson MLE, EM) | **Default; deeply implemented.** Stable, denoises well, decent even without an imported PSF. |
| **Automatic** | RL with auto noise level + auto-stopping, iteration cap by modality | One-click RL. Our `auto_*` defaults reproduce it. |
| **Landweber** | Wavelet-regularized Landweber, solved by **FWISTA** (`min ‖Ax−b‖₂ + λ‖x‖₁`) | Fastest iterative; less noise than RL, slightly less stable. Scaffold. |
| **Blind** | Iterative *asymmetric* blind deconvolution (alternately re-estimate image then PSF) | PSF only roughly known; top quality but RAM-heavy and can diverge. Scaffold, off by default. |
| **Fast** | **Wiener** inverse filter (single-pass Fourier-domain division) | Real-time / preview; can ring. Cheap to add (`scipy`/FFT). |
| **MAP / MAP Automatic** | Maximum-a-posteriori energy minimization w/ non-negativity + priors | Robust to noise, good background/boundary handling; slower. Scaffold. |
| **Live De-Blur** | Fast-like, streaming | Out of scope (no live stream in ND2Studios). |

The registry design (§4) makes each of these a selectable `DeconvolutionMethod` so we can
land RL first and add the others without re-plumbing.

### 2.4 The point spread function (PSF)

The PSF is the single most important input; a wrong PSF gives confidently wrong results.
Two ways to obtain it (both offered, per Nikon):

**(a) Theoretically computed PSF** — from the optical path. Two standard scalar-diffraction
models:
- **Born & Wolf** — the classic scalar model for an aberration-free objective imaging in a
  medium that matches its design (no refractive-index mismatch). Good baseline.
- **Gibson–Lanni** — extends Born & Wolf to a **stratified** specimen (immersion medium,
  coverslip, sample) with mismatched refractive indices and thicknesses, so it models the
  **depth-dependent spherical aberration** that dominates real 3D widefield data. This is the
  model we target; a fast, accurate approximation exists (Li, Xue & Blu 2017) and is what
  `flowdec` / `PSFGenerator` use. Born & Wolf is the degenerate no-mismatch case.

The computed PSF is parameterized by (all available from ND2 metadata or a ParamSpec
fallback): **NA**, **emission wavelength**, **immersion refractive index** `n_i`, **sample
refractive index** `n_s`, **lateral pixel size**, **axial Z-step**, and — for spherical
aberration — the **acquisition depth** into the sample. Confocal adds **pinhole size**,
**excitation wavelength** and **magnification**; a confocal PSF is approximately the
widefield PSF modulated by the pinhole (in the closed-pinhole limit, ~PSF²).

**(b) Measured PSF** — image a **sub-resolution bead** (ideally smaller than one pixel) on
the *same* system with the *same* settings (objective, Z-step, zoom), on a black (0)
background; for 3D, a Z-stack ND2; for 2D, a TIFF. Nikon's hard rule (we echo it in the UI):
*every* acquisition setting must match, or results are unreliable. A measured PSF captures
real, system-specific aberrations a model can't.

**Sampling.** Deconvolution assumes Nyquist-sampled data. Under-sampling (voxels too large
vs the diffraction limit) caps achievable resolution and can introduce artifacts; the node
should compute the ideal lateral/axial sampling from NA/λ/`n` and warn when the ND2 voxel
size is coarser (Nikon's "Proper Sampling" guidance).

**Depth-variant PSF.** Because spherical aberration grows with depth, Nikon can split a tall
stack into *layers* and compute a separate aberrated PSF per layer. We expose the same
`sa_layers` control (default 1 = single PSF).

### 2.5 Nikon NIS-Elements — the implementation we follow

Nikon exposes three **commands** — *3D Deconvolution* (strictly Z-stack ND2), *2D
Deconvolution* (single frame or frame-by-frame over any ND2; noted as inferior to 3D on
Z-stacks), and *Live De-Blur*. Within a command, the **method** is chosen from §2.3.

**Table A — Nikon *Automatic* iteration caps** (we reproduce these as `auto` defaults):

| Data | Iterations |
|---|---|
| 3D widefield | 90 |
| 3D non-widefield (confocal, etc.) | 60 |
| 2D widefield | 120 |
| 2D non-widefield | 60 |

**Nikon dialog parameters we mirror** (→ our ParamSpec in §5): Deconvolution Method;
Modality; Pinhole/Slit size + orientation; Magnification; Numerical Aperture; Immersion Ref.
Index (with medium presets); Calibration (µm/px); Z-Step; Excitation & Emission wavelength;
**Noise Level** (Automatic, or Custom **SNR 1–50** where 1 = very noisy, 50 = almost

Estimation** (Automatic / Off / Manual — subtract before, add back after); Advanced: **Remove
Spurious High-Intensity Pixels**, **Spherical Aberration Correction** (Acquisition Depth +

**Convert to Float**, **Run on ROI**, **Preview**.

## 3. The architectural problem, and the 3D-first decision

Deconvolution fits **neither** existing paradigm cleanly:

- `EnhancementPlugin` is `(T,H,W) → (T,H,W)` and only ever sees **Z-collapsed** data
  (the loader projects Z at load; even `z_mode="none"` pins a *single* plane). A plugin
  therefore *cannot* do true 3D deconvolution — the Z axis is already gone.
- `DVCMethod` is Z-aware (`(Z,H,W)`) but returns a **displacement/strain field**, not an
  image; its whole result/viewer machinery is field-shaped.

Deconvolution is a **hybrid**: Z-aware like DVC, but **image→image** like enhancement (its
output is a restored volume that downstream steps want to consume). This is a genuinely new
result type, so — following the precedent set when DVC and Registration each got their own
registry — **deconvolution gets its own `DeconvolutionMethod` registry** and a Z-aware data
path via `get_volume()`, and is wired as a pipeline-graph node (not a recipe step, not a
sidebar page).

**Restore-then-project bridge.** Because the rest of ND2Studios operates on `(T,H,W)`, the
node offers two output modes:
- **`project`** (default): deconvolve the `(Z,H,W)` volume per `(t,c,m)`, then Z-project
  (max/mean) into the normal `(T,H,W)` stream so existing export/recipe steps work unchanged
  — "deconvolve in 3D, then project" (strictly better than projecting first).
- **`volume`**: keep the full restored `(T,Z,H,W)` stack for the multi-axis viewer / TIFF
  export.

This is the key call that makes a 3D-first feature coexist with a Z-collapsing pipeline.

## 4. Key decisions

- **New registry, mirrored on DVC/Registration.** `core/deconvolution_registry.py` defines
  `DeconvolutionMethod` (ABC), `DeconvolutionResult`, and reuses `ParamSpec` verbatim.
  Backend-pure (no PySide6).
- **Dimension-agnostic engine, 3D-first.** One RL implementation over `d ∈ {2,3}`; a
  `(1,H,W)` volume with a 2D PSF *is* the 2D case. No separate 2D code path.
- **FFT-based convolution** (`scipy.fft` / `numpy.fft`) with reflect-padding to fast
  (power-of-2 / 5-smooth) sizes; optional **CuPy** GPU path behind `importlib.util.find_spec`
  (mirrors how cellpose/stardist are optional in this repo — never in `requirements.txt`).
- **RL is the default and the only deeply-built method** for V1.63; Landweber/Wiener/Blind/
  MAP are registered stubs raising a friendly "not yet implemented" until phased in.
- **Computed PSF via Gibson–Lanni** (Born & Wolf as the no-mismatch fallback); **imported
  measured PSF** supported and, when present, disables the computed-PSF params (as Nikon does).
- **Optical params auto-filled from metadata**, each overrideable: `objective_na`,
  `channel_emission_nm`, `channel_excitation_nm`, `objective_immersion` (→ `n_i`),
  `pixel_size_um`, `z_step_um` from `read_nd2_metadata_extended()`; **all may be `None`**, so
  every one has a ParamSpec fallback. Sample RI is not in metadata → default **1.35**.
- **Nikon-faithful parameters & naming** (§5), including SNR 1–50, Auto-Stopping, background
  subtract/restore, spherical-aberration layers, hot-pixel removal, convert-to-float, ROI.
- **Per-`(t,c,m)` streaming.** Deconvolve one volume at a time via `get_volume(c,m,t)` so a
  tens-of-GB, many-timepoint ND2 never fully materializes; report progress across the sweep.
- **`float32` internally**, output `float32` when "Convert to Float" (default for new docs),
  else cast back to source dtype with clipping.

## 6. Data source (no loader changes)

Same raw-Z accessor the DVC node uses. `LazyND2Volume.get_volume(c, m, t, z_start, z_end)`
and `MaterializedDataset.get_volume(...)` both return `(Z, H, W)` (a single-Z dataset yields
`(1, H, W)` → the 2D case). Physical scale comes from `record.pixel_size_um` / `z_step_um`
→ `voxel_size_um = (z, y, x)`. Optical metadata for the computed PSF comes from
`read_nd2_metadata_extended()` (`objective_na`, `channel_emission_nm`,
`channel_excitation_nm`, `objective_immersion`); **every field may be `None`**, so the engine
resolves each as `metadata_value if not None else paramspec_default`. No changes to the
loader, recipe, or export code are required — deconvolution reads volumes directly and either
projects into the existing `(T,H,W)` stream or emits a `(T,Z,H,W)` stack.

## 8. Code skeletons

### 8.1 `core/deconvolution_registry.py` (backend-pure)

```python
from __future__ import annotations
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from typing import Any, Callable, Dict, List, Optional, Tuple, Type

import numpy as np
from nd2studios.core.plugin_registry import ParamSpec   # reuse, do not duplicate


@dataclass
class DeconvolutionResult:
    """Restored image + provenance. `restored` matches the input shape/axes:
    (Z,H,W) for a 3D run (Z may be 1) — the caller projects or keeps the volume."""
    restored: np.ndarray
    dim: int                              # 2 or 3
    method: str = ""
    psf: Optional[np.ndarray] = None      # the PSF actually used (for QC)
    iterations_run: int = 0
    converged: bool = False
    voxel_size_um: Tuple[float, ...] = ()
    diagnostics: Dict[str, Any] = field(default_factory=dict)


class DeconvolutionMethod(ABC):
    """Base class for all deconvolution methods. Subclasses set `name`/`description`
    and decorate with `@DeconvolutionMethod.register` so the node + headless callers
    can discover them and read their `get_params()`."""
    name: str = "Unnamed"
    description: str = ""
    _registry: Dict[str, Type["DeconvolutionMethod"]] = {}

    @classmethod
    def register(cls, method_cls):
        DeconvolutionMethod._registry[method_cls.name] = method_cls
        return method_cls

    @classmethod
    def get_methods(cls): return list(DeconvolutionMethod._registry.values())

    @classmethod
    def get_method(cls, name): return DeconvolutionMethod._registry.get(name)

    @abstractmethod
    def get_params(self) -> List[ParamSpec]: ...

    @abstractmethod
    def run(self,
            volume: np.ndarray,                    # (Z,H,W); Z==1 → 2D case
            voxel_size_um: Tuple[float, ...],      # (z,y,x)
            optics: Dict[str, Any],                # na/emission_nm/ni/ns/... (metadata-resolved)
            params: Dict[str, Any],                # ParamEditor.get_values()
            progress_cb: Optional[Callable[[int], None]] = None,
            cancelled_cb: Optional[Callable[[], bool]] = None) -> DeconvolutionResult: ...
```

### 8.2 `backend/deconvolution/richardson_lucy.py` — the core (FFT, accel, TV, GPU)

```python
from __future__ import annotations
from typing import Callable, Optional
import numpy as np
from scipy import fft as sp_fft


def get_array_module(use_gpu: bool):
    """Return cupy if requested & importable, else numpy (optional-dep idiom)."""
    if use_gpu:
        import importlib.util
        if importlib.util.find_spec("cupy") is not None:
            import cupy as cp
            return cp
    return np


def _next_fast_shape(shape, xp):
    return tuple(sp_fft.next_fast_len(int(s)) for s in shape)   # 5-smooth → fast FFT


def richardson_lucy(image: np.ndarray, psf: np.ndarray, num_iter: int = 40, *,
                    accelerate: bool = True, tv_lambda: float = 0.0,
                    snr: Optional[float] = None, clip_negative: bool = True,
                    edge: str = "reflect", xp=np,
                    progress_cb: Optional[Callable[[int], None]] = None,
                    cancelled_cb: Optional[Callable[[], bool]] = None) -> np.ndarray:
    """N-D (2D or 3D) accelerated, TV-regularized Richardson–Lucy.

    x_{k+1} = x_k · ( ĥ ⊛ ( d / (h ⊛ x_k) ) ),  ĥ = mirrored PSF  = conj(OTF) in Fourier.
    Poisson-MLE, non-negative, intensity-conserving. `snr` sets the correction-ratio floor
    (ε ≈ peak/snr); `tv_lambda`>0 adds Dey et al. (2006) edge-preserving TV.
    """
    img = xp.asarray(image, dtype=xp.float32)
    psf = xp.asarray(psf, dtype=xp.float32)
    psf = psf / psf.sum()                                    # normalize → conserve intensity

    full = tuple(i + p - 1 for i, p in zip(img.shape, psf.shape))   # linear-conv size
    fshape = _next_fast_shape(full, xp)
    pad = tuple((0, fs - i) for fs, i in zip(fshape, img.shape))
    d = xp.pad(img, pad, mode=edge)                          # reflect-pad to curb ringing
    eps = xp.float32((d.max() / snr) if snr else 1e-6)

    otf = xp.fft.rfftn(_center_pad_psf(psf, d.shape, xp))
    otf_c = xp.conj(otf)

    est = xp.full_like(d, float(d.mean()))                   # flat init (robust for RL)
    prev = est
    g_prev = None
    for k in range(num_iter):
        if cancelled_cb and cancelled_cb():
            break
        if accelerate and k >= 2:                            # Biggs–Andrews prediction
            alpha = _accel_alpha(g_prev, g_prev2)            # ∈[0,1], from successive grads
            est = xp.clip(est + alpha * (est - prev), 0, None)
        blur = xp.fft.irfftn(xp.fft.rfftn(est) * otf, d.shape)
        ratio = d / xp.maximum(blur, eps)
        corr = xp.fft.irfftn(xp.fft.rfftn(ratio) * otf_c, d.shape)
        if tv_lambda > 0:
            corr = corr / (1.0 - tv_lambda * _tv_divergence(est, xp))
        prev, g_prev2, g_prev = est, g_prev, (est * corr - est)
        est = est * corr
        if clip_negative:
            est = xp.clip(est, 0, None)
        if progress_cb:
            progress_cb(int((k + 1) / num_iter * 100))

    out = est[tuple(slice(0, i) for i in img.shape)]         # crop to original
    return xp.asnumpy(out) if xp is not np else out
```

`_center_pad_psf`, `_accel_alpha` (Biggs–Andrews line-search on successive correction
gradients), and `_tv_divergence` (`div(∇x/|∇x|)`) are small helpers in the same module.
2D vs 3D needs **no branching** — every op is N-D. `cupy` swaps in via `xp`; on GPU we can
optionally cast to `float16` for the FFTs on very large volumes.

## 10. Performance & memory

- **FFT is the cost.** Pad each volume to a 5-smooth `next_fast_len` shape; reflect-pad to
  curb edge ringing. Reuse the OTF across iterations (compute once per volume/PSF).
- **Stream per `(t,c,m)`** via `get_volume` — never materialize the whole `(T,Z,H,W)`. Peak
  memory ≈ a few × one padded volume in `float32`.
- **Tiling** (`tile_xy`, `tile_overlap`) splits huge frames and blends overlaps to bound FFT
  memory on large cameras.
- **GPU (optional).** `use_gpu` routes `xp` to CuPy when importable; the flowdec benchmark
  (≈1000×1000×11 + same-size PSF) shows ~10 min CPU → ~40 s FFT-GPU → ~1 s full-GPU, so GPU is
  the headline speedup for 3D. Kept an optional dependency (`find_spec`), never in
  `requirements.txt`.
- Runs in a worker `QThread` (existing `BaseWorker` pattern) with `progress`/`cancelled`;
  `cancelled_cb` is polled between iterations and between volumes.

## 11. Testing & validation

- **Synthetic oracle:** build a known phantom (points, shells, bars), convolve with a known
  PSF, add Poisson noise, deconvolve, and check recovery (SSIM/PSNR ↑, FWHM of point sources
  → toward diffraction limit) — the pattern DVC uses (synthetic known-deformation oracle).
- **Intensity conservation:** total signal preserved to a tolerance across iterations (RL
  invariant); **non-negativity** holds.
- **PSF validation:** compare `synthesize_psf` against `PSFGenerator`/`flowdec` reference PSFs
  for matched parameters (they validate to high similarity).
- **2D == degenerate 3D:** a `(1,H,W)` volume through the 3D path equals the 2D result.
- **Edge/ringing:** reflect-pad vs zero-pad on a high-contrast phantom; assert reduced border
  artifacts.
- **Backend purity:** `grep -r PySide6 nd2studios/backend/deconvolution/` is empty (repo rule);
  headless run (no Qt) green.
- **GUI end-to-end** on a real 3D ND2 (launch the app), preview + full run, project + volume
  outputs, imported-PSF path.

## 13. Risks

- **PSF correctness is the top risk** — a wrong PSF gives plausible-looking wrong results.
  Mitigate: validate synthesis against references; default `sa_correction=on`; make measured
  PSF easy; warn on sampling/parameter mismatch.
- **Over-iteration noise amplification** — cap at Nikon's ranges, default TV on (`Low`),
  `auto_stop` on.
- **Memory blow-ups on big 3D** — streaming + tiling + `float32`; surface an estimate before run.
- **Metadata gaps** (`None` NA/emission/RI) — every optical value has a ParamSpec fallback;
  the node shows which values came from metadata vs defaults.
- **Backend purity** — grep-gated; all math under `backend/deconvolution/` is Qt-free.
- **Scope creep** — only RL/Automatic are built in V1.63; other methods are registered stubs.
