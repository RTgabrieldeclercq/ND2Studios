# V1.46 — Restore the original Cell-Tracker spatial-map construction (griddata)

## Goal

Replace ND2Studios' spatial-map *construction* with the method used by the
**original Cell-Tracker repository** (`Cell-Tracker/CellTracker/backend/fields.py`
+ `pages/spatial_page.py`): `scipy.interpolate.griddata` linear interpolation of
per-cell measurements onto the grid. Data collection stays identical (Cell-Tracker
tracking + StarDist segmentation feed the same tracked DataFrame), and **every
current spatial-map functionality is preserved** — grid step / σ, colour scale
(auto / global / manual), all field types (`FIELD_OPTIONS` + arbitrary `col:`
columns + `self_fold`), cell-mask source, image overlay, cell borders, quiver,
scale bar, templates, zoom/pan, frame strip / playback, and in-tab Save.

## Background — what diverged

The V1.46 "compute every field the way cell density is computed"
(`V1.46_spatial_maps_density_method.md`) rewrote the construction from the
original `griddata` interpolation to a **binned Gaussian-weighted local mean +
cell-footprint mask**. Density was left unchanged. This task reverts that
construction to the original Cell-Tracker method while keeping the V1.46 *viewer*
work (the in-tab panel, templates, zoom/pan) intact.

## Original construction (the reference being restored)

- **Density** — binned centroid count per grid bin, Gaussian-smoothed. (Identical
  in both versions; unchanged.)
- **Scalar fields** (`mean_area`, `intensity`, `fold_change`) —
  `griddata(points, values, (grid_y, grid_x), method="linear")`, gaps filled with
  the frame mean via `nan_to_num(nan=np.nanmean(values))`, then `gaussian_filter`.
  Needs ≥4 cells (else all-NaN).
- **Velocity** — per-track displacement `pos(t) − pos(t−1)`, `griddata` linear,
  `nan_to_num(nan=0)`, `gaussian_filter`; needs `len(merged) > 3`. `speed` =
  magnitude; `divergence`/`curl` = `np.gradient` of the velocity grid.
- **`self_fold`** (panel) — `compute_self_fold_change` then `griddata` linear with
  `nan_to_num(nan=1.0)` + `gaussian_filter`.
- **`_pixel_fields`** (image-based intensity / fold_change when a channel image is
  shown) — grid-block mean of the raw pixels. **Unchanged** — already verbatim
  from the original in both versions.

## Trade-off (noted deliberately)

The binned method was introduced to stop scalar fields from "inventing" values in
empty space between cells (griddata fills the whole convex hull with the frame
mean). Restoring the original method reinstates that behaviour, by design — it is
how the original Cell-Tracker plots spatial maps, which is what this task asks for.
