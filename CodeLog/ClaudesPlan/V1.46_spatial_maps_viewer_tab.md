# V1.46 — Spatial Maps → interactive in-viewer tab (+ template library)

## Goal

Turn the two spatial-map sink nodes — **Cell-Tracker Spatial Maps**
(`special:ct_fields`) and **Interpolated Spatial Maps** (`special:interp_map`) —
from parameter-heavy, export-to-disk nodes into parameter-less nodes that **open
an interactive "Spatial Maps" tab in the Pipelines image viewer**. The tab is a
faithful reproduction of the sibling Cell-Tracker repo's spatial page (same
controls, same rendering, same behaviour). Add a reusable **template** system so a
node carries one or more saved configurations that auto-load on the next run.

## Decisions (confirmed with the user)

- **Both** nodes open the same tab. The tab unifies the Eulerian fields *and*
  "interpolate any measurement column" in one **Field** dropdown.
- **Sidebar layout:** docked viewer → a top toolbar of section dropdowns whose
  options appear as a lateral button row; maximized viewer → the full vertical
  Cell-Tracker sidebar. Same widgets, reparented on `set_compact`.
- **Export:** an in-tab **Save** button (current frame / all frames, PNG or
  raw-field TIFF) replaces the old folder export.
- **Templates:** saved to a **global JSON library**; a node stores template
  **names** and resolves them at run time. For portability the picker/tab can
  **import an external JSON file** into the local library. **Run = open the tab
  pre-loaded** (no auto-export).
- **Representation matches the original repo** — `_compute_frame` / `_pixel_fields`
  / `_compute_self_fold_field` / `_draw_frame` ported essentially verbatim.

## Approach

1. **`widgets/spatial_maps_panel.py` (new)** — `SpatialMapsPanel` ports
   Cell-Tracker's `SpatialPage` over ND2Studios' already-vendored
   `backend/celltracker/fields.py` (`compute_spatial_fields`, `FIELD_OPTIONS`),
   `metrics.compute_self_fold_change`, `backend/interp_maps.compute_interp_map`,
   `widgets/scale_bar.draw_scale_bar`, `widgets/common.MplCanvas`,
   `image_viewer.frame_to_uint8`. Dual sidebar via `set_compact(bool)` (section
   "body" widgets reparented between a compact top-bar flyout and a full vertical
   collapsible sidebar). Own frame slider; optional M selector
   (`m_change_requested`). `get_config`/`apply_config`; template strip
   (Save / Load-file / preset combo) + `set_node_templates`. In-tab Save.
   `SpatialTemplatePicker(QDialog)` edits a node's template list.
2. **`backend/spatial_templates.py` (new, pure)** — JSON template library under
   `~/.nd2studios/spatial_map_templates`: `list/load/save/delete_template`,
   `read_template_file`, `import_file`, `export_file`.
3. **`backend/celltracker_bridge.build_tracked_df(rows, m)`** — rows → full
   CellTracker DataFrame (`{ch}_mean` + passthrough numeric metric columns).
4. **`pages/pipelines_page.py`** — viewer is now a `QStackedWidget` (image viewer
   ↔ panel); new **"Spatial Maps"** overlay tab + `"spatial"` key.
   `_on_overlay_tab_changed` / `_select_overlay_tab` swap the stack;
   `_update_overlay_tabs_available` gates the tab on measured rows;
   `_toggle_popout("viewer")`/`_restore` toggle `set_compact`. New
   `_ensure_spatial_panel`, `_open_spatial_maps_tab`, `_populate_spatial_panel`,
   `_label_stack_for_m`, `_edit_spatial_templates`. Preview + Run dispatch for
   both ops route to `_open_spatial_maps_tab`. Removed `_preview_field_maps`,
   `_show_field_popup`, `_preview_interp_maps`, `_show_map_popup`,
   `_run_ct_fields`, `_run_interp_maps`, `_inject_value_columns` and the dead
   `export_field_maps` / `export_interp_maps` imports.
5. **`pipeline_graph/registry_adapter.py`** — both ops now expose a single hidden
   `templates` list param (default `[]`); descriptions updated. Old saved graphs
   with the legacy params still load (extra keys harmless; `templates` defaults
   to `[]`).

## Verification

Headless smoke test passed (offscreen Qt): panel construction, compact↔full
layout switching, field switching (density / intensity / self-fold / `col:`
column), cell-mask + borders + scale-bar render, `get_config`/`apply_config`
round-trip, and template save/load/delete + picker. Manual checklist: build
analysis → Track Objects → Cell-Tracker Spatial Maps; preview/run opens the tab;
compare each field against Cell-Tracker; maximize → full sidebar; Save current /
all frames; save a template, attach it via "Spatial map templates…", re-run and
confirm auto-load; import a template JSON for portability.
