## 1. Node 4 — "View granule in 3-D" (reuse, don't build)

Per decision 3, Node 4 is **not** a new node — it is a view path on the existing
PyVista stack. Wire a "View in 3-D" affordance (mirroring the DVC/PTV "View in 3-D"
buttons, `V1.65_pyvista_3d_viewer.md §8.3–8.4`) that, for the current `(m,t)`:

- Reads `record._granule_masks_by_m[m][t]` (`{id:(Z,H,W) bool}`).
- For each granule, `viz3d.surface.build_object_surface(mask, voxel_size_um,
  smooth_iterations=…, taubin_lambda=…)` → `ObjectSurface` (marching cubes + Taubin).
  **The wishlist "smoothing parameter" maps to these existing knobs** — expose them on
  the viewer control (or read from the mask node's `smooth_sigma` sibling).
- **Scalars painted on the surface** (`_add_surface_field_overlay`, per-vertex
  point-data, divergent/sequential cmap — `pyvista_viewer.py:734`):
  - `label` — flat per-granule color (categorical).
  - `displacement` / `strain` — the DVC-on-object path: when DVC has run,
    `dvc_object_surface(result, mask, mask_voxel_size_um, scalar_keys=…)` produces a
    `SurfaceField` with `u_perp/u_par/e_xx…/eff_strain` + MDM (`overlays.py:513`,
    `surface.py`). Feed `PyVista3DViewer.set_overlay(sf, scalar=…)`.
  - arbitrary per-voxel scalar — generalize `sample_displacement_on_surface`
    (`surface.py:272`) to sample any `(Z,H,W)` scalar field onto the vertices.
- A granule selector (largest by default, matching the V1.68 DVC-object first cut) or
  "all granules" multi-actor scene.

Gated exactly like the rest of the 3-D subsystem: pyvista absent ⇒ `Missing3DDeps`
placeholder; nothing else changes.
