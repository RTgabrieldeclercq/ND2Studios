# V1.70 · P2 — Granule Clustering node (`special:granule_cluster`)

**Depends on:** P0 contracts. **Concurrent with:** P1, P3–P5. **Pure backend + one
page handler.**

## Goal

Answer "which granule does each bead belong to" via a **Gaussian Mixture Model**
(full covariance) with the user-seeded granule count **relaxed by ±p%** and selected
by **BIC**. Output an initial per-point label array (P3 refines it with the density
merge).

- **Optional sklearn**, lazy + `find_spec`-gated (P0 §7): friendly `ImportError`
  ("Granule clustering needs scikit-learn — `pip install scikit-learn`"). Follow the
  `serialtrack/prediction.py:175` lazy-import precedent.
- Scale coords to µm (isotropic) before fitting so anisotropic Z doesn't bias the
  Gaussians: `pts_um = points_zyx * (dz,dy,dx)`.
- **BIC sweep** (P0 decision 5): `k_lo=max(1, round(n*(1-p)))`, `k_hi=round(n*(1+p))`;
  for each `k` fit `GaussianMixture(k, covariance_type="full", n_init=…, random_state
  fixed)`, record `gm.bic(pts_um)`; pick `argmin`. Return `predict` labels + the
  `bic_by_k` curve (surfaced in the node's status/plot).
- **KMeans fallback** (decision 4 alt): a `method` param (`gmm|kmeans`) exposes the
  spherical KMeans path for sparse/unstable clouds; same BIC→(inertia/silhouette)
  selection.
- Robustness: guard tiny N (`N < k_hi` ⇒ clamp k), `scipy.spatial.QhullError`-free
  (no tessellation here), NaN/degenerate covariance retry with `reg_covar` bump.
- Write `granule_id` back into the DATA rows (initial labels) and store
  `record._granule_labels_by_m[m][t]`.

**Params** (P6): `n_granules` (int, the seed n), `relax_pct` (float 0–100, the ±p%),
`method` (choice `gmm|kmeans`), `n_init` (int), `all_multipoints` (bool). `random_state`
fixed internally for reproducibility (no `Math.random` needs).

## Page handler — `_run_granule_cluster(node)`

Synchronous per `(m,t)`: read `record._granule_points_by_m[m][t]`; if absent, clear
status "wire a Bead Detect node upstream" and finish. Call `cluster_granules`, store
labels, update rows, `_run_finish_node`. Optionally emit the BIC curve to the node's
preview plot (reuse the existing per-node plot surface).

## Verification

- 3 well-separated planted blobs, seed n=5, relax 60% → BIC picks k≈3; labels match
  planted assignment (adjusted Rand ≈ 1).
- Elongated (anisotropic covariance) blob → full-covariance GMM keeps it as one
  cluster (spherical KMeans would split it — asserts the covariance choice matters).
- sklearn-absent → friendly `ImportError`, app otherwise unaffected (gating test).
- Deterministic across runs (fixed `random_state`).
