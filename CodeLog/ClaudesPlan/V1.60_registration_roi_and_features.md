# V1.60 — Registration: late-frame robustness + region- & feature-based estimation

**Status:** Implemented
**Related review:** `Research/image_registration.md` (§1.2, §2.1 masked, §2.3 ORB+RANSAC, §4.4 pitfalls)
**Builds on:** V1.56 (registration node), V1.59 (`RegisteredFrameVolume` display base)

## Goal

Two things, one change set:

1. **Fix the reported bug** — registration is excellent on the first frames of a
   timelapse but degrades at later timepoints. Root-caused (reproduced on a 30-frame
   synthetic) to: no confidence gating by default (the engine's NCC already collapses
   on failed frames but a spurious shift was applied anyway), `previous`-mode error
   accumulation, photobleaching/SNR decay, and phase-correlation wrap.
2. **Add the reliability features** the user asked for — **region-of-interest (ROI)**
   estimation (lock onto a static landmark; ignore moving cells/artifacts) and a
   **feature-based (ORB+RANSAC) model** (large motion / rotation / scale / multi-round).

## Approach (all in the pure engine + method + node UI; apply-path unchanged)

### Phase 0 — late-frame robustness (`estimate.py`, `method.py`)
- `estimate_translation`: `phase_cross_correlation(..., disambiguate=True)` (wrap guard).
- `estimate_series`: **hold-last-good gating** — when `confidence < min_confidence`,
  reuse the previous good transform (absolute modes) or skip the increment
  (`previous`) instead of snapping to identity; return a per-frame `gated` bool.
- `normalize="zscore"` per-frame normalization (photobleaching).
- New `reference="template"` two-pass anchor (`_build_template`): rough-stabilize with
  a cheap `previous` translation pass → average → register every frame to that
  template. Robust to accumulation and to a bleached/atypical single anchor frame.
- `RigidRegistration` defaults: `reference="template"`, `min_confidence=0.2`; new
  `normalize` param. (Reproduction: late-frame error 285 px → 10 px; `previous` no
  longer explodes.)

### Phase 1 — ROI (`estimate.py`, `registry_adapter.py`, `pipelines_page.py`)
- `roi_to_mask(roi, shape)` → `(mask, bbox)` (rect→box mask+bbox; shapes→rasterized
  via `manual_mask.rasterize_shapes`).
- `estimate_translation(..., mask, bbox)`: rectangle → crop to bbox (subpixel);
  freeform → masked phase correlation (integer). `ecc_align(..., mask)` → ECC
  `inputMask` (full-frame coords, correct rotation center). `estimate_series(roi=…)`
  rasterizes once and forwards; confidence measured over the region.
- Node: hidden `roi` `ParamSpec`; a **"Pick ROI…"** popup button
  (`_edit_registration_roi`) — a dialog for whole-frame / rectangle (x/y/w/h
  spinboxes) / freeform (arms the viewer `set_draw_mode`, captured one-shot in
  `_on_registration_shape`). Stored serializably in `node.params["roi"]`; rides
  through `_RegisterJob` → `method.run(params["roi"])` (no job change needed).

### Phase 2 — feature model (`estimate.py`, `method.py`)
- `estimate_features(reference, moving, transform, mask, bbox, min_inliers, …)` — ORB
  keypoints + `match_descriptors(cross_check=True)` + `ransac` (Euclidean/Similarity/
  Affine); warp maps reference→moving (matches `apply_warp` WARP_INVERSE_MAP);
  confidence = inlier fraction; too few inliers → identity (fallback).
- `estimate_series`: `model=="feature"` branch → `(T,2,3)` warps (composes for
  `previous`/`template`). Method adds `"feature"` to `model`, plus `feature_transform`
  + `min_inliers` (visible_when model=feature).

### Panel (`registration_panel.py`)
`set_data(gated=, min_confidence=)`; the drift plot shades **held (low-confidence)**
frames in red and the meta line counts them — so late-frame degradation is visible.

## Addendum — Crop to common region (post-approval, translation only)

Requested after approval: crop all registered frames to the largest rectangle that is
real (non-padded) data in **all** frames, so frames are equal-size, recentred, and
border-free. Chosen behavior: **everywhere downstream**, **single region across all M**,
**translation only**.

- `estimate.common_translation_crop(shifts, shape, inset_edges=True)` — analytic
  rectangle intersection of per-frame valid footprints (1 px inset per padded side).
- Node toggle `crop_to_common` (`registry_adapter`, `visible_when model=translation`).
- `_finish_register` → `_compute_common_crop(node, by_m)` stacks every M's shifts and
  publishes `record._registration_crop = (y0,y1,x0,x1)` (or None).
- **Single chokepoint:** `_crop_rect()` composes the published crop with any preview
  crop (`_registration_crop_rect` + `_intersect_crop_rects`), so it reaches analysis
  (`_processed_channels_for_m`), export/validation/spatial (`_materialize_channels_for_m`),
  the viewer base (`_maybe_crop_volume`), the write-back (`_crop_frame`), and the panel —
  no per-site changes. Register → crop (V1.59 order preserved). Cleared on each Run start.
- Tests: valid-region math + no-leaked-borders, no-overlap → None, no-drift → full frame,
  end-to-end (stage-drift moving-window model) equal-size border-free co-registered frames.
  Offscreen: param present + `visible_when`, `_intersect_crop_rects`, `_compute_common_crop`
  (single region across 2 M; off/feature → None). 33 registration tests pass.

## Addendum — viewer playback perf (registered image played slowly)

Reported: the registered image plays slowly in the viewer while the raw plays fast.
Root cause (traced): the registered display is the lazy `RegisteredFrameVolume`, whose
`get_frame` ran a full-resolution warp (`scipy.ndimage.shift` / `cv2.warp`) on **every**
frame with **no cache** and `bypass_pyramid=True`, so playback/scrubbing recomputed it
each tick — whereas the raw streams a pyramid/RAM plane. The write-back also pushed the
full-res materialized stack via `set_channels` (no pyramid).

- **Cache** `RegisteredFrameVolume` (`executor.py`): memory-budgeted LRU (512 MB) of
  warped display frames keyed `(c,m,t,z,z_mode)` — mirrors `ProcessedFrameVolume`;
  deterministic per `(m,t)` so safe. Each frame warps once; loops are instant.
- **Display path** `_apply_registration_writeback`: for lazy-volume files, refresh via the
  cached lazy volume (`_show_base_image`) instead of full-res `set_channels`
  (`_processed_channels` is still set for downstream / `processed_view()` compat).
- Test: `test_registered_frame_volume_caches_warps` (base read/warp once per plane;
  no-transform M passes through uncached). 34 registration tests pass.
