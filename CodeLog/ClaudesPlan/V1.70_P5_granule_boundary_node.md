# V1.70 · P5 — Boundary Extraction node (`special:granule_boundary`)  [wishlist Node 5]

**Depends on:** P0 contracts. **Concurrent with:** P1–P4. **Pure backend + one page
handler.**

## Goal

From the labeled voxels, extract an **outward** boundary band of thickness N —
voxels within N of each granule's surface whose label ≠ that granule (i.e.
"the direction that there is not the same value": background **and** neighbor
granules). Used to mask the raw/DVC volume and recover data around each granule.

- **Dilation method (default):** `band_i = binary_dilation(mask_i, iterations=N) & (combined_labels != i)`.
  Uses a 3-D structuring element; `combined_labels != i` keeps voxels that are
  background **or** another granule (P0 decision 9). Optionally exclude the granule's
  own voxels explicitly.
- **EDT method (option):** `edt = distance_transform_edt(~mask_i, sampling=(dz,dy,dx))`;
  `band_i = (edt > 0) & (edt <= N * min(voxel)) & (combined_labels != i)` — a
  **metric** band honoring anisotropic voxel size (dilation is a voxel-count band).
  `scipy.ndimage.distance_transform_edt` already used in `mask3d.py:97`.
- Combined band-label volume: paint band voxels with their source granule id (a voxel
  in two bands → nearest-surface granule via the EDT argmin, or lowest id; document).

**Params** (P6): `band_voxels` (int N), `band_method` (choice `dilation|edt`),
`band_um` (float; `visible_when band_method==edt`, overrides N·voxel if set),
`include_neighbors` (bool default True — if False, `& (combined_labels == 0)` for
background-only per the alt option), `all_multipoints` (bool).

## Page handler — `_run_granule_boundary(node)`

Per `(m,t)`: read `record._granule_masks_by_m[m][t]` (per-granule bool + `"_labels"`);
guard missing; call `extract_boundary_bands`; store
`record._granule_bands_by_m[m][t]`. `_run_finish_node`. The bands are `(Z,H,W) bool`
per granule → they can themselves feed `iter_objects` / DVC-on-object to correlate
the surrounding matrix.

## Verification

- Single cube granule, N=2, dilation: band is exactly the 2-voxel outward shell,
  0 voxels of the granule's own label inside it; touches nothing when isolated.
- Two adjacent granules: band of granule A includes granule-B voxels within N
  (default) and excludes them when `include_neighbors=False`.
- **Dilation vs EDT agree at N=1** on isotropic voxels; EDT band is anisotropy-correct
  when `(dz,dy,dx)` differ.
- Empty/one-voxel granule handled without error.
