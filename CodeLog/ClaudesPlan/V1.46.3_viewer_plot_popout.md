# V1.46.2 — Maximize / pop-out the viewer and plots panel

## Goal

On the Pipelines page, give the user a way to maximize either the **image
viewer** or the **plots / data panel** into a full standalone window — and dock
it back — while preserving all live state (overlay tabs, sliders, channel LUTs,
zoom/pan, and the plot/measurements tabs).

## Approach

The cleanest way to "conserve its current state (all tabs, etc.)" is to **reparent
the live widget** rather than rebuild a copy. The very same widget instance is
moved out of the right-hand vertical splitter into a `QDialog`, shown maximized,
and moved back into its original splitter slot when the dialog closes. No state
serialization is needed because nothing is recreated.

### New widget — `widgets/popout_window.py`

`PopOutWindow(QDialog)` borrows a widget, hosts it full-window
(`Qt.WindowType.Window`, non-modal), and calls a host-supplied
`on_restore(widget)` callback exactly once (covering both the title-bar close
button and a programmatic `restore()`), via a guarded `_hand_back()`.

### Pipelines page wiring (`pages/pipelines_page.py`)

- **Viewer button**: the overlay tab bar is wrapped in an `HBox` with a trailing
  `fa5s.expand` icon button. The whole `_viewer_container` (overlay tabs + image
  + controls) is what pops out.
- **Plots button**: a `fa5s.expand` icon button is set as the `_data_tabs`
  `QTabWidget` top-right corner widget. The whole `_data_tabs` (Measurements +
  plot tabs) pops out.
- `_toggle_popout(kind)` pops out (or docks back if already out). Restore
  re-inserts at the original splitter index (viewer→0, plots→1; `QSplitter`
  index clamping makes any pop-out/restore order correct), swaps the button icon
  `expand` ⇄ `compress`, and re-applies docked visibility via
  `_update_merged_view_mode()`.
- `_popout_windows: Dict[str, Optional[PopOutWindow]]` tracks live windows.
- `_set_panel_visible(kind, visible)` replaces the direct
  `_viewer_container.setVisible` / `_data_tabs.setVisible` calls so the existing
  Results image/table/split mode logic never hides a panel that is currently
  living in its own pop-out window.

## Files

- `nd2studios/widgets/popout_window.py` — new reusable `PopOutWindow`.
- `nd2studios/pages/pipelines_page.py` — two maximize buttons, `_toggle_popout`,
  `_set_panel_visible`, guarded visibility call sites, imports.

## Key decisions

- **Reparent, don't rebuild** — guarantees identical state on both directions.
- **Scope = Pipelines page** — it is the only page hosting both an image viewer
  *and* a plots/data tab panel together (the "all tabs" the request refers to).
- **Non-modal maximized window** — the user can still drive the main window.
